# 사각형 월드 · Quadrilateral World

사각형으로 캐릭터를 만들고, 그 캐릭터로 탐험·전투·성장을 즐기는 Godot 4 횡스크롤 학습 RPG입니다. 초등 수학 4-2 「4. 사각형」의 성질을 주민들의 부탁을 해결하며 복습합니다.

## 메인페이지와 그림 그리기

게임을 실행하면 메인페이지에서 **그림 그리기**, **집 짓기**, **모험 시작하기**, **도형 도감**을 선택할 수 있습니다.

**그림 그리기**는 빈 도화지에 사각형을 조합하는 자유 창작 공간입니다. 정사각형·직사각형·사다리꼴·평행사변형·마름모를 고른 뒤 도화지를 누르거나 드래그해 추가합니다. 만든 도형은 선택해 이동하고, 색·회전·크기를 바꾸거나 복제·삭제할 수 있습니다. 되돌리기와 다시 실행, 앞뒤 순서 변경, PNG 내보내기를 제공합니다. 변형해도 선택한 사각형의 성질은 유지됩니다.

그림은 모험 캐릭터와 별도로 `user://quadrilateral_drawing_v1.json`에 자동 저장됩니다. 메인으로 돌아갔다가 다시 들어와 이어서 그릴 수 있으며, 그림 편집은 캐릭터와 퀘스트 진행에 영향을 주지 않습니다. 웹에서는 같은 사이트와 브라우저의 저장소를 사용합니다.

## 뚝딱! 사각형 집 짓기

**집 짓기**는 부탁을 듣고 집 앞모습을 만드는 독립된 2D 건축 게임입니다. **5단계·10가지 부탁**을 고르며, 낮은 단계의 집을 완성해 번 돈과 저축으로 높은 단계를 엽니다. 같은 단계의 부탁을 다시 받아 돈을 더 모을 수 있습니다. 처음에는 정사각형·직사각형만 사용하고, 이후 사다리꼴·평행사변형·마름모를 차례로 배웁니다. 지붕은 평평한 직사각형을 비롯해 여러 모양을 사용할 수 있습니다.

공식 LEGO Bricktales, Townscaper, House Flipper 2, Dragon Quest Builders 2를 참고해 큰 재료 카드와 **부탁 보기 → 집 짓기 → 튼튼한지 확인 → 보상 받기** 흐름을 적용했습니다. 새 ImageGen 원화 14종을 버튼·패널·재료·인물·공사장·배지에 사용합니다. [참고 조사](docs/CONSTRUCTION_GAME_REFERENCES.md), [생성 원본과 프롬프트](assets/generated/construction-game/GENERATION.md)에 제작 근거를 기록했습니다. 어려운 말은 쉬운 말로 바꾸고 재료 설명과 **쉬운 말 사전**을 제공합니다.

| 단계 | 사용하는 모양 | 해금에 필요한 누적 이익 / 저축 |
|---|---|---|
| 1 | 정사각형·직사각형 | 처음부터 가능 |
| 2 | 사다리꼴 추가 | 600만 원 / 3,600만 원 |
| 3 | 평행사변형 추가 | 2,000만 원 / 5,000만 원 |
| 4 | 마름모 추가, 다섯 모양 조합 | 4,500만 원 / 7,500만 원 |
| 5 | 다섯 모양, 더 넓은 집과 창문 | 7,500만 원 / 1억 500만 원 |

새 단계는 바로 앞 단계의 집도 완성해야 합니다. 먼저 받은 돈을 제외한 실제 완성 이익과 저축만 해금에 사용합니다. 모든 부탁은 정해진 재료값을 전부 써도 기본 이익이 남아 반복해서 진행할 수 있습니다.

**명예의 전당**은 3단계 이상에서 튼튼한 집을 완성했을 때 디자인 기준에 따라 선정합니다. 다섯 항목 합계 60·70·80·90·97점에서 **5단계 배지**를 받으며, 높은 배지일수록 원화가 화려해집니다. 알림과 완성 기록에서 배지를 확인하고 **PNG 저장**을 누르면 1200×800 집 그림의 **왼쪽 위에 받은 배지**가 붙습니다. 격자·손잡이·치수·UI는 내보내지 않습니다. [배지 평가 기준](docs/CONSTRUCTION_AWARDS.md)을 참고하세요.

건축 사무소 화면은 자재 견본·입면 도면·의뢰 조건·견적을 함께 다루는 작업대로 구성됩니다. 자재를 종류별로 고르고, `설계 보기`의 눈금·치수선과 `재료 보기`의 질감·그림자를 전환할 수 있습니다. 치수는 게임 격자인 ‘칸’으로 표시합니다. 완공 기록에는 집의 입면 미리보기를 보관합니다. [디자인 참고와 적용 내용](docs/CONSTRUCTION_DESIGN.md)에 화면 설계 근거를 기록했습니다.

재료는 기존 40종에 직사각형 평지붕 2종을 더한 **42종**입니다. 마름모 창·석재 구조 블록, 평행사변형 콘크리트 벽체·지붕·보, 사다리꼴 처마·외장판, 정사각 지붕·타일 등 여러 용도와 규격을 고를 수 있습니다. ‘대표 모양’과 ‘용도’ 필터로 찾아보세요. 포함 관계에 따른 수학 분류는 유지합니다. 카드에는 폭·높이, 선택한 자재에는 실제 네 변의 길이를 표시합니다. 의뢰에도 도형과 길이·길이 종류 수에 관한 선호 조건이 있습니다. 1칸은 게임 좌표 20이며 미터 단위가 아닙니다. 이미 계약한 이전 저장은 당시 조건을 보존합니다. [전체 자재 목록](docs/CONSTRUCTION_MATERIALS.md)을 참고하세요.

메인 삽화·의뢰인·재료·아이콘·UI 종이는 **ImageGen 생성 PNG**를 사용합니다. 모험의 기존 생성 이미지도 유지합니다. [생성 파일과 최종 프롬프트](assets/generated/revision/GENERATION.md)에 교체 내역을 기록했습니다. 사용자가 만든 사각형과 수학 격자·치수·선택 표시는 실제 기하 데이터로 렌더링합니다.

메인은 세 놀이를 한눈에 고르는 화면이며, 집 짓기는 저대비의 작업 바탕에 도면·재료·부탁을 나누어 표시합니다. 큰 장식 프레임이나 원근 풍경을 도면 뒤에 늘려 놓지 않습니다. [게임 화면 참고와 적용](docs/FOCUSED_GAME_DESIGN.md), [UI 표면 생성 기록](assets/generated/focused-ui/GENERATION.md)에 근거를 정리했습니다.

1. 의뢰서의 문·창문·도형 조건과 건축비를 확인하고 계약금을 받습니다.
2. 문과 창문은 **벽을 쌓는 동안 비워 둔 공간에 배치**합니다. 벽돌이 문·창문 자리를 침범할 수 없습니다. 주변 벽과 창턱, 위쪽 받침보를 완성합니다.
3. 재료 선반에서 **벽돌 한 장**과 **벽돌 9장 묶음**을 바꾸어 사용합니다. 다섯 사각형으로 된 지붕과 장식도 놓을 수 있습니다. 첫 집은 파란 윤곽과 `안내대로 놓기`로 27단계 배치 예시를 따라 완성할 수 있습니다. 받침보를 네 개 이어 양쪽 처마 아래까지 채웁니다. 안내를 접고 자유롭게 설계하거나 `기초 배치 도움`만 사용해도 됩니다.
4. **시공 검사**를 누르면 설계 복사본에 실제 Godot 2D 중력·충돌·질량·회전이 적용됩니다. 서로 맞닿은 구조재는 모르타르로 연결된 덩어리로 계산합니다. 문과 창은 지붕의 하중을 받치지 않으며, 떠 있거나 불안정한 구조물은 떨어지거나 기웁니다. `설계로 돌아가기`로 원래 위치에서 다시 고칠 수 있습니다.
5. 새 의뢰는 안정성 외에도 **바닥부터 지붕까지 외벽이 이어졌는지** 검사합니다. 버티고 있어도 벽이나 처마 아래에 빈틈이 있거나, 외벽 일부에 지붕이 없으면 납품할 수 없습니다. 안정성과 필수 부탁을 만족하면 의뢰인에게 집을 보여 주고 정산합니다. 추가 선호를 만족할수록 보너스가 늘어납니다. 계약금 중복 지급과 같은 집의 재정산을 막으며, 완성한 집은 기록에서 다시 볼 수 있습니다.

검사에서 실패하면 **고칠 곳 보기**에서 재료별 원인과 고치는 방법을 확인합니다. **이 재료 고치기**를 누르면 원래 설계의 해당 재료를 선택하고 화면 가운데 보여 줍니다. 테두리와 ‘고칠 재료’ 표식으로 문제 재료를 표시하고, 문·창문의 받침이 부족한 변은 굵은 선과 `!`로 표시합니다. 설계를 바꾸면 이전 진단을 지우므로, 수정 후 시공 검사를 다시 해 주세요.

외벽 검사에서 실패하면 결과 창의 **외벽 빈틈 위치 보기**로 붉은 영역을 확인하고 채웁니다. 실제 네 꼭짓점의 교차 구간을 검사하므로 경사진 지붕 아래의 작은 틈도 찾으며, 지붕의 처마 돌출과 문·창문 자리, 벽에 붙인 장식은 구별합니다. 이전에 수락하거나 정산한 의뢰는 당시 판정과 장부를 보존하고, 다음 새 의뢰부터 외벽 완성 조건을 적용합니다.

이미 지은 부분이 있을 때 `기초 배치 도움`을 누르면 예시로 바꾸기 전에 확인합니다. 취소하면 현재 설계와 장부를 그대로 유지하고, 교체한 뒤에도 `되돌리기`로 복원할 수 있습니다. 자재 목록과 대화창은 키보드로 고른 항목이 보이도록 스크롤하며, 열린 대화창도 창 크기에 맞춰 조절됩니다.

학교 PC·노트북 웹브라우저를 기준으로 마우스·키보드 조작, 확대와 이동을 지원합니다. 재료 선택 후 클릭 또는 방향키와 Enter로 배치하고, 선택한 재료는 드래그·방향키·이동 버튼으로 옮깁니다. `Shift+방향키`로 반 칸씩 정밀 이동합니다. 휠로 확대하고 오른쪽 버튼으로 화면을 끌거나 `집에 맞추기`로 작품을 가운데 볼 수 있습니다. 좁은 화면의 의뢰 조건과 장부는 위쪽 `의뢰·장부` 버튼에서 확인합니다. 완공 후에는 편집 도구를 접고 다음 의뢰 버튼을 표시합니다.

금액은 **한국 원화, 토지 제외**이며 100원 배수입니다. 공개 판매가에 근거한 재료와 묶음 가격을 사용하고, 비정형 가공품과 기본 공사비의 게임용 가정은 따로 표시합니다. `199,500,000원 / 1억 9,950만 원`처럼 큰 수를 함께 읽고, 장부에서 계약금·재료비·기본 공사비·보너스·이익을 구분합니다. [가격 자료와 적용 기준](docs/CONSTRUCTION_PRICES.md), [CC0 이미지 출처](docs/CONSTRUCTION_ASSETS.md)를 참고하세요.

건축은 `user://quadrilateral_construction_v1.json`에 자동 저장합니다. 그림과 모험 저장을 덮어쓰지 않습니다. 저장 내용 전체를 검증한 뒤 복원하며, 저장 중 중단되거나 본 파일이 손상되면 유효한 임시 파일·백업에서 복구합니다. 건축 중인 집은 재접속 후 시공 검사를 다시 해야 합니다. 완공한 집은 이전 판정 기준의 기록도 정산과 진행 상황을 유지합니다.

## 모험 캐릭터를 만드는 방법

메인페이지에서 **모험 시작하기**를 선택하면 기존 캐릭터 공방으로 들어갑니다.

1. 공방에서 **로봇 루미, 고양이 모모, 딱정벌레 토토** 중 골격을 고릅니다.
2. **사다리꼴·평행사변형·마름모·직사각형·정사각형** 중 알맞은 도형을 골라 골격을 채웁니다.
3. 위치, 크기, 회전, 색을 조절해 나만의 캐릭터를 완성합니다. 도형은 선택한 종류의 성질을 유지합니다.
4. 옆모습으로 움직이는 캐릭터와 함께 마을·숲·계곡·항구·설원·성곽의 여섯 지역을 탐험하고 주민을 도와줍니다.

모든 골격 부위를 채우면 월드에 들어갈 수 있습니다. `색칠된 예시 사용` 버튼으로 완성 예시부터 시작할 수도 있습니다. 기존 삼각형 도안의 일치율, 별점, 도전 미션은 새 플레이 흐름에서 제거했습니다. 공방의 골격은 움직이는 캐릭터를 만드는 안내도입니다.

## 모험과 학습

별빛 축제를 준비하던 마을에 항구 등대가 꺼졌다는 소식이 도착합니다. **초록 마을 → 바람 숲 → 평행 계곡 → 사다리 항구 → 거울 설원 → 별빛 성곽**을 여행하며 끊어진 빛길을 다시 이어 주세요. 지역별 이야기와 등장인물은 [이야기 안내](docs/story.md)에 정리했습니다.

H로 이야기 수첩을 열어 여섯 장의 진행을 확인하세요. 지역의 부탁을 모두 마치면 결말이 기록되고, 항구 등대·설원 거울·성곽 별빛 장치가 실제 월드에서 밝아집니다. J의 ‘이 목표 안내’ 버튼은 남은 물품이나 돌아갈 주민의 방향을 표시합니다.

16명의 주민에게 서로 다른 부탁이 있고 목표 물품은 총 41개입니다. 마름모 초콜릿 4개와 정사각형 강아지 두부를 찾고, 항구의 사다리꼴 돛, 설원의 거울 창, 성곽의 별빛 핵까지 모아 보세요.

**주민을 만나기 전에도 물건과 같은 높이로 다가가면 수집됩니다.** 가까운 물건은 `G`로 직접 주울 수도 있습니다. 미리 찾은 물건은 가방에 남아 해당 부탁을 받는 즉시 반영됩니다. 물건을 충분히 모은 뒤 주민과 도형 질문을 풀면 보상을 받습니다. 정답만 골라 수집을 건너뛸 수는 없으며, 오답에는 설명이 나오고 물건을 잃지 않고 다시 생각할 수 있습니다.

여행길에는 두 번 공격하면 물리칠 수 있는 몬스터 7마리가 있습니다. 몬스터 처치와 부탁 완료로 경험치를 얻고, 레벨이 오르면 최대 체력이 늘어나며 체력을 모두 회복합니다. 처음에는 회복약 3개를 받습니다. 회복약은 체력 40을 회복하며 잡화점에서 10코인에 구입할 수 있고, 쉼터에서는 5코인으로 충분히 쉴 수 있습니다. 체력이 다 떨어져도 코인과 물건을 잃지 않고 쉼터에서 무료로 회복합니다.

관문에서는 직접 발견한 지역으로 빠르게 이동할 수 있습니다. 가방에서 회복약과 모은 퀘스트 물품을 확인하세요. 이야기의 순서는 여행 안내이며, 학습 퀘스트는 다른 부탁·전투 승리·레벨에 잠기지 않습니다.

교재와 동일하게 **평행한 변이 있는 사각형을 사다리꼴**로 분류합니다. 따라서 정사각형은 직사각형, 마름모, 평행사변형, 사다리꼴의 성질도 갖습니다. 도형을 회전해도 분류는 바뀌지 않습니다. 자세한 교재 대응표와 구현 범위는 [PRD.md](PRD.md)를 참고하세요.

## 실행과 저장

Godot 4를 설치한 뒤 프로젝트 폴더에서 실행합니다.

```powershell
powershell -File tools/run_game.ps1
```

또는 Godot에서 `project.godot`를 열고 프로젝트를 실행합니다. Godot은 `PATH`, WinGet 설치 폴더, CreatorTemp에서 찾으며, 다른 위치라면 `GODOT_EXE` 환경 변수나 `-GodotExe` 옵션으로 지정할 수 있습니다.

| 모드 | 조작 |
| --- | --- |
| 메인페이지 | 그림 그리기 / 집 짓기 / 모험 시작하기 / 도형 도감 선택 |
| 집 짓기 | 재료 클릭 배치, 문·창 공간 확보, 선택·드래그/방향키 이동, 휠 확대, 오른쪽 끌기, 시공 검사·정산 |
| 그림 그리기 | 클릭·드래그로 추가, 몸통으로 이동, 변·꼭지점으로 비율 유지 확대·축소, 원형 손잡이로 회전 |
| 공방 | 마우스로 골격·도형 선택, 도형 드래그, 화면의 크기·회전·색상 조절 |
| 편집 되돌리기 / 다시 실행 | `Ctrl+Z` / `Ctrl+Y` |
| 선택 도형 복제 / 삭제 | `Ctrl+D` / `Delete` |
| 저장 | `Ctrl+S` 또는 저장 버튼 |
| 월드 좌우 이동 | `A`, `D` 또는 `←`, `→` |
| 점프 | `Space`, `W` 또는 `↑` |
| 앞쪽 몬스터 공격 | `Z` 또는 `F` |
| 주민과 대화 / 가까운 물건 조사 | `E` |
| 가까운 물건 줍기 | `G` (또는 물건 곁에서 `E`) |
| 상점·쉼터·관문 이용 | 가까이에서 `E` |
| 회복약 사용 / 가방 | `Q` / `I` |
| 부탁 목록 / 지도 | `J` / `M` |
| 여섯 지역 이야기 | `H` |
| 모험 메뉴 열기 | `Tab` 또는 `Esc` |
| 메뉴·대화창 버튼 이동 / 선택 | `Tab`, `Shift+Tab` / `Enter` |
| 대화·목록 닫기 | `Esc` |

공방 도구로 15° 회전과 같은 비율의 확대·축소를 할 수 있으며, PNG 버튼으로 캐릭터 그림을 내보낼 수 있습니다. `Ctrl+Shift+Z`도 다시 실행으로 동작합니다.

작은 창에서는 공방과 모험 메뉴가 화면에 맞게 재배치됩니다. 글자와 버튼은 월드 축소율과 별도로 표시합니다. 부탁 수첩은 진행 중·새 부탁·완료·전체로 나누어 볼 수 있으며, 긴 대화와 목록은 창 안에서 스크롤됩니다. 메뉴를 닫으면 원래 선택한 버튼으로 돌아갑니다.

그림 그리기에서는 선택하거나 조작하는 도형의 네 변 길이가 **그림 단위**로 표시됩니다. 화면 크기가 달라져도 길이는 같으며, `Shift`를 누르고 회전하면 15°씩 맞출 수 있습니다. **자석 스냅**은 가까운 다른 도형의 꼭지점과 변에 맞추며 안내선을 표시합니다. `Alt`를 누르는 동안 스냅을 잠시 끄고, `Esc`로 진행 중인 조작을 취소할 수 있습니다. 56색 팔레트와 직접 색 선택을 제공합니다.

**배경 30종**에는 도시·바다·우주·산·집과 숲, 농장, 성, 항구 등 서로 다른 장면이 있습니다. **명화 채우기**에서는 별이 빛나는 밤, 해바라기, 아를의 침실, 모나리자, 진주 귀걸이를 한 소녀, 가나가와 해변의 높은 파도, 수련, 빨강·파랑·노랑의 구성, 절규, 사과 바구니를 바탕으로 만든 사각형 밑그림 10종을 고릅니다. 밑그림을 보이거나 숨기고 진하기를 조절하며 자유롭게 채울 수 있습니다. 배경·밑그림·모드 선택도 되돌릴 수 있고 기존 도형은 유지됩니다.

그림은 `user://quadrilateral_drawing_v1.json`에 자동 저장됩니다. 예전 그림 저장 파일도 열 수 있으며, 새 저장에는 배경과 명화 선택이 포함됩니다. 그림의 PNG 저장은 960×600 크기로 배경과 작품을 내보내고 격자·밑그림·길이 표시·손잡이를 제외합니다. [배경 프롬프트와 명화 제작 기록](assets/generated/drawing/GENERATION.md)에서 출처를 확인할 수 있습니다.

캐릭터, 퀘스트, 미리 수집한 물건, 체력·경험치·회복약, 물리친 몬스터, 발견한 지역과 위치는 자동 저장되며 저장·불러오기 버튼으로도 관리할 수 있습니다. 저장 위치는 Godot 사용자 데이터 폴더의 `user://quadrilateral_world_v1.json`입니다. 기존 세 지역에서 진행한 저장도 이어서 사용할 수 있습니다. 모험 상태가 없던 이전 저장은 이미 완료한 부탁의 경험치를 반영합니다. 웹에서는 같은 사이트의 브라우저 저장소를 사용하므로 브라우저 데이터 삭제 시 저장도 사라질 수 있습니다.

## 검증과 빌드

```powershell
# 사각형 기하, 공방, 퀘스트, RPG 상태, 저장 및 월드 검증
powershell -File tools/run_tests.ps1

# 웹 배포 파일
powershell -File tools/export_web.ps1

# 설치된 Godot으로 실행하는 Windows 패키지
powershell -File tools/export_desktop.ps1
```

웹 빌드 결과는 `build/web`, Windows 패키지는 `build/windows`에 생성됩니다. Windows 패키지의 `Run_QuadrilateralWorld.bat`이 `QuadrilateralWorld.pck`를 실행하며, 실행할 PC에 Godot 4가 필요합니다. 웹 빌드를 로컬에서 확인하려면 `python tools/serve_web.py`를 실행하고 안내된 주소를 엽니다. 빌드의 한글 폰트 처리에는 Python과 `tools/requirements-font.txt`의 패키지가 필요합니다.

GitHub·Vercel에 새 버전을 올리는 절차는 [배포 안내](docs/DEPLOYMENT.md)를 참고하세요.

# Browser arrival illustration

[night-village.webp](night-village.webp) is the first-paint illustration in the browser loading and recovery screen. The built-in OpenAI ImageGen tool generated this 1672 × 941 image with an opaque background. The project’s [home arrival panorama](../home-atlas/arrival.webp) was its visual reference. The browser export copies the full image, encoded as WebP at quality 82, directly to the release. This directory is excluded from the game resource pack with `.gdignore`.

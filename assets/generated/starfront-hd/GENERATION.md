# 고해상도 원화 교체

2026-11-01. 사용자 요청: 기존 우주 개척 분위기와 톤을 유지하며, 작은 이미지를 크게 표시해 흐릿해지는 자산을 ImageGen으로 다시 제작한다.

기존 3×3 배경 시트의 장면당 약 557×314픽셀을 각각 독립된 1672×941픽셀 이미지로 교체했다. 원본 픽셀을 그대로 늘린 파일이 아니라 세부를 새로 그린 생성 결과다. 환경물은 잘린 실루엣을 막기 위해 실제 불투명 영역을 측정한 좌표로 자른다. 일반 재료 패치는 약 512×512픽셀, 긴 부재는 가로 2172픽셀을 사용한다.

실루엣·배치·색감·투명도를 검수했다. 기존 단일 벽돌 원본, 주민·아이템·작은 도구, 금속 UI 스킨, 학습 그림·벡터 도해는 용도에 충분한 크기여서 유지했다. 수학 도형과 한글은 이미지에 굽지 않으며 원래 렌더러를 사용한다. 배포에서는 교체된 작은 배경·환경·재료 시트를 제외하지만 저장소에는 이력과 참고 원본으로 남긴다.

원화 보관소의 최초 생성 파일은 그대로 보존한다. Starbound의 원본 그림·스프라이트·로고·음원을 포함하지 않는다.

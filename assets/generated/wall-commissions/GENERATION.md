# 벽 꾸미기 의뢰의 빈 벽 배경

2026-11-23, 내장 ImageGen으로 각 의뢰의 배경을 **서로 독립된 요청 열 번**으로 생성했다. 외부 사진이나 기존 게임 그림을 사용하지 않았다. 공통 지시는 “가로형 손그림 교육용 게임 배경, 중앙에 정면으로 본 직사각형 회벽, 네 변을 가리는 물건 없이, 벽 안쪽에는 타일·그림·문구가 없는 따뜻한 크림색 회벽을 남긴다”였다. 아래 표의 장소 설명을 각각의 요청에 지정했다.

1672×941 원화를 1280×720 WebP로 맞추었다. 타일이 테두리나 기둥 위로 번지지 않도록 배경별로 회벽의 네 변을 확인했다. 표의 좌표는 이미지 왼쪽 위가 (0, 0), 오른쪽 아래가 (1, 1)인 값이며, 런타임에서 쓰는 값은 `scenes/wall/wall_art.gd`에서 관리한다.

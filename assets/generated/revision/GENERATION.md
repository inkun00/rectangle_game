재료 이미지는 실제 네 꼭짓점에 맞춰 표시한다. 원본 벽체 견본의 시각적 벽돌 개수가 정확하지 않아, 실제 장수를 세는 9장·2장·8장 묶음은 생성된 단일 벽돌 픽셀을 각각 3×3·1×2·2×4로 반복 배치한다. 석재 등 벽돌 장수를 세지 않는 벽체는 해당 재질 전체를 사용한다. 새 벽돌 그림을 코드로 그리지는 않는다. 창과 문도 생성 픽셀을 사용하며 외곽·충돌·빈 공간은 검증된 기하 데이터가 결정한다.

인물과 아이콘의 투명 배경을 확인했다. 아이콘 1차 원본은 사용하지 않고, 잡티 제거와 사다리꼴 집 아이콘을 요청한 교정본을 사용한다. 이미지의 텍스트에는 의존하지 않으며 한국어·가격·조건·치수는 게임 UI 텍스트로 표시한다.

의뢰인 재생성: 사용자가 만화 캐릭터 느낌을 요청하여 내장 ImageGen의 스타일 변환으로 여섯 인물을 모두 선명한 윤곽선·표정·셀 음영의 2D 웹툰 캐릭터로 바꿨다. 기존 인물별 머리 모양·나이·옷 색과 3×2 순서를 유지했다. 픽셀 편집 없이 새 결과를 같은 파일에 복사했으며, 이전 원본과 프롬프트는 `prompts.json`의 해당 항목 `history`와 기본 생성 폴더에 남아 있다. 아틀라스 각 셀의 좌우 4%를 표시 영역에서 제외하여 이웃 인물의 소매 조각을 숨긴다. 위아래 영역과 머리·얼굴은 그대로 유지한다.

기존 모험의 배경·지형·건물·NPC·수집물·몬스터·패널은 이미 ImageGen으로 생성된 9개 원본을 계속 사용한다. 출처와 프롬프트는 [기존 제작 기록](../GENERATION.md), [확장 지역 기록](../EXPANSION-GENERATION.md)에 있다. 사용 중인 삽화·인물·질감·아이콘은 모두 이 생성 원본들에서 온다. 기존 Kenney PNG와 SVG 아이콘은 이전 제작 자료로 남아 있으나 활성 화면에서는 참조하지 않는다.

사용자가 직접 조립하는 네 꼭짓점 작품, 템플릿 기하 가이드, 격자·눈금·치수선·선택 테두리·검사 경고는 정확한 수학·입력 피드백을 위해 기하 데이터로 렌더링한다. 생성 이미지의 외형에서 길이나 도형 종류를 추측하지 않는다.

# 사각형 월드 공통 버튼

2026-10-29, 내장 ImageGen으로 만든 게임 UI 원본입니다. CLI/API fallback과 외부 게임 에셋은 사용하지 않았습니다. [실제 생성·편집 프롬프트](prompts.json)를 함께 보관합니다.

| 파일 | 용도 | 생성 출력 |
| --- | --- | --- |
| `secondary.png` | 밝은 종이 타일의 일반 버튼 | `exec-b05a8091-9a57-4b2c-a14f-d4e88c86d877.png` |
| `primary.png` | 짙은 초록 타일의 주요 행동·선택 버튼 | `exec-fe9b2d7e-a9a8-455c-b182-c2972f4beb5e.png` |
| `check-off.png` | 체크 해제·색상 칩의 종이 프레임 | `exec-e734ff9f-bff3-4306-8391-9399071cb88a.png` |
| `check-on.png` | 체크 선택 표시 | `exec-2a1bcc3a-e2af-4c72-9b20-ae713e62cabd.png` |

네 파일 모두 실제 투명 배경을 요청했습니다. 기본 버튼을 생성한 뒤 주요 행동 버전은 색만 바꾸는 편집으로, 체크 해제 이미지를 생성한 뒤 선택 버전은 체크 표시를 더하는 편집으로 제작했습니다. 배경·패널 이미지의 확대 재사용 대신 버튼 전용 그림을 사용합니다.

`scripts/ui/button_art.gd`는 불투명 실루엣으로 투명 여백을 찾고, 원본 영역을 UI 해상도에 맞게 샘플링해 아홉 영역으로 늘립니다. 밝은/짙은 원본과 런타임 상태색으로 일반·가리킴·누름·선택·사용 불가 상태를 표시합니다. 한글은 원본에 굽지 않고 실제 버튼 글자로 렌더링하며, 초점 테두리도 생성 그림의 불투명 영역을 사용합니다. 색상 선택의 값과 게임 데이터는 바꾸지 않습니다.

메인, 그림 그리기, 캐릭터 공방, RPG HUD·대화·가방·상점·지도, 집 짓기, 선택 메뉴, 색상 팝업, 파일 저장창과 웹 재시도에 공통 적용합니다. 웹 로딩 버튼은 동일 원본의 UI 샘플을 `tools/export_button_web.gd`로 함께 내보냅니다. 텍스트 링크와 수학 격자·도형·색상 값은 원래 의미와 동작을 유지합니다.

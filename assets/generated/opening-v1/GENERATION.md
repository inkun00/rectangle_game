# 오프닝 원화 — 별빛 고향으로

2026-11-03. 사용자가 요청한 이야기: 사각형 행성의 외계인이 지구에 불시착하고,
사각형 그림 판매와 집 건축 의뢰로 돈을 벌어 새 우주선을 만들어 귀향한다.

모든 신규 원화는 **내장 `image_gen.imagegen`**으로 생성했다. CLI/API 키 또는
유료 영상 생성 서비스를 사용하지 않았다. 생성 원본을 그대로 이 폴더에 복사했으며,
투명 이미지의 알파를 유지했다. 애니메이션에서 원화의 위치·회전·크기와 아틀라스
표시 영역을 바꾼다. 원본 이미지 파일을 덧그리거나 편집하지 않았다.

정확한 전체 프롬프트와 투명 배경 설정은 [prompts.json](prompts.json)에 있다.

| 파일 | 실제 크기 / 형식 | 용도 | 생성 파일 ID |
| --- | --- | --- | --- |
| alien.png | 1254×1254 RGBA | 동일 외계인의 탐험가·놀람·화가·건축가 2×2 포즈 | exec-eaae66b2-d07e-41f6-8356-4da91e7d0a6a |
| ship.png | 1536×1024 RGBA | 오른쪽을 향한 사각형 패널 우주선 | exec-32873f61-51be-4738-9644-49c8902546d5 |
| planet.png | 1254×1254 RGBA | 사각형 행성의 입체 전경 | exec-f120d734-1f0e-4542-af16-d51a6f73e962 |
| earth.png | 1672×941 RGB | 지구의 시골 마을과 비어 있는 작업 공간 | exec-5d7a2514-50e1-449f-b5b2-01602a953374 |

창작 방향은 민트색 네모 머리, 크림색 우주복, 산호색 목도리의 작은 외계인과
청록·남색·구리색의 종이극이다. 한글은 생성 이미지에 넣지 않고 로컬 글꼴로
선명하게 렌더했다. 사람 손님 두 명은 기존 생성 원화
`assets/generated/starfront-v1/crew.png`의 셀 6과 0을 재사용했다.

정확한 사각형 그림과 건축 부품, 동전, 설계도는 애니메이션 코드로 그린다.
그림과 집의 조립은 각각의 사각형을 시간에 따라 이동시킨다. 플레이어가 직접
만든 캐릭터나 저장된 도형은 변경하지 않는다.

이 원본은 재편집용 자산이다. 앱 배포에는 렌더된 OGV와 포스터만 포함한다.
음악과 효과음도 외부 샘플 없이 이번 영상용으로 작곡·합성했다.

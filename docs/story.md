# 별빛을 잇는 사각형 여행

사각형 월드의 주민들은 매년 별빛 축제를 연다. 별빛 성곽의 장치에서 나온 빛은 거울 설원을 거쳐 사다리 항구의 등대로 이어진다. 그런데 올해는 등대가 꺼졌고, 눈보라가 거울 창과 길의 표식을 흩어 놓았다. 플레이어는 직접 만든 사각형 캐릭터로 여섯 지역을 여행하며 주민들의 일을 돕고 빛길을 되찾는다.

이야기는 여행의 방향을 알려 준다. 모든 주민의 부탁은 처음 만났을 때 받을 수 있으며 다른 부탁이나 전투를 끝낼 필요가 없다. 물건부터 발견해도 곧바로 가방에 들어간다. 나중에 주민을 만나 부탁을 받으면 이미 모은 수량이 인정된다. 이야기를 순서대로 보거나 먼 지역부터 탐험하는 선택은 플레이어에게 맡긴다.

## 여섯 지역의 이야기

| 장 | 지역 | 주민과 역할 | 다음 이야기로 이어지는 단서 |
| --- | --- | --- | --- |
| 1 · 별빛 축제의 아침 | 초록 마을 | 초코 제빵사의 간식과 지붕 장인 모루의 손님맞이 준비를 돕는다. | 축제에 켜져야 할 항구 등대가 보이지 않는다. |
| 2 · 숲길에서 만난 친구들 | 바람 숲 | 숲지기 나래의 강아지 두부를 찾고, 길잡이 직이와 목수 평이의 여행길 정비를 돕는다. | 등대를 살피러 떠나는 사람들이 계곡 도서관의 기록을 찾는다. |
| 3 · 꺼진 등대의 소식 | 평행 계곡 | 측량사 자로의 길 표식, 사서 네리의 기록, 촌장 도담의 축제 배지를 찾는다. | 성곽·설원·항구가 하나의 빛길로 연결되어 있다. |
| 4 · 사다리 항구의 잠든 등대 | 사다리 항구 | 선장 바루의 돛과 창고지기 네모의 도구 상자를 모아 등대 수리 준비를 돕는다. | 설원에서 온 편지에 흩어진 거울 창 이야기가 있다. |
| 5 · 거울 설원의 빛길 | 거울 설원 | 등불지기 루리의 불빛, 길잡이 설이의 썰매길, 유리 장인 미로의 거울 창을 준비한다. | 다시 쓸 거울을 비출 빛은 별빛 성곽에서 시작된다. |
| 6 · 다시 빛나는 사각형 월드 | 별빛 성곽 | 성곽지기 반듯의 깃발, 기록관 아린의 인장, 별지기 루나의 별빛 핵을 모은다. | 친구들의 준비가 모이면 빛이 성곽에서 설원과 등대를 거쳐 축제를 밝힌다. |

지역의 부탁을 모두 마치면 해당 장의 마무리를 보여 준다. 성곽을 먼저 마쳤다면 다른 지역의 남은 부탁도 안내한다. 전체 여정의 완성은 16명의 부탁을 모두 도운 상태로 표현하며, 마지막 부탁 하나만 완료했다고 다른 지역의 일이 자동 완료되지는 않는다.

## 구현 데이터

`QuestCatalog.all_quests()`가 이름·대사·수량·학습 피드백·보상과 아이템/NPC 이미지 정보를 제공한다. `region_story(region_id)`의 반환값은 `title`, `intro`, `outro`이며 없는 지역은 빈 사전이다. 이야기 진행률의 원본은 `QuestJournal.completed`다. 별도의 스토리 완료 플래그를 중복 저장하지 않는다.

기존 물품은 `items_atlas`, 기존 주민은 `npc_atlas`를 사용한다. 주민의 기존 이미지 순서는 제빵사, 지붕 장인, 숲지기, 길잡이, 목수, 측량사, 사서, 촌장이다. 확장 물품은 `expansion_items`, 확장 주민은 `expansion_npcs`를 사용하고 `item_icon`과 `npc_icon`은 모두 0부터 7까지다.

| 확장 이미지 번호 | NPC ID | 목표 ID |
| ---: | --- | --- |
| 0 | `sailor` | `trapezoid_sail` |
| 1 | `keeper` | `rectangle_crate` |
| 2 | `lamplighter` | `rhombus_lantern` |
| 3 | `tracker` | `parallel_track` |
| 4 | `glazier` | `square_window` |
| 5 | `guardian` | `parallel_banner` |
| 6 | `archivist` | `rectangle_seal` |
| 7 | `astronomer` | `square_core` |

기존 퀘스트 ID·목표·정답·보상을 유지해 확장 전 저장을 이어서 사용할 수 있다. 이전 세 지역의 발견 기록은 유효하며 새 지역은 직접 찾아 발견한다. 수락 전 모은 물품도 저장에 포함되어 다시 접속해도 사라지지 않는다.

# 운영 파일과 외부 격리 자료

2026-11-10 정리 기준이다. Git에는 실행 코드·장면·현재 사용하는 자산, 라이선스와 생성 출처, 저장 형식과 배포 문서, 테스트 및 재현 가능한 빌드 도구를 보관한다.

| 항목 | 정리 전 | 정리 후 |
| --- | ---: | ---: |
| Git 추적 파일 | 759개 | 495개 |
| 운영 소스 용량(Git 이력·캐시·재생성 결과물 제외) | 약 392MB | 약 132MB |
| 변환한 이미지 66개 | 148.16MB | 109.25MB |

MB는 1,000,000바이트 기준이다. 운영 소스는 약 66% 줄었다. 원본 백업과 격리 자료는 위 용량에 포함하지 않는다.

## 이미지

실사용 PNG 66개를 무손실 WebP로 변환했다. 합계 148,155,884바이트에서 109,251,652바이트로 줄었다. 38,904,232바이트(26.26%)를 절감했으며, 모든 이미지의 크기와 디코딩한 RGBA 전체 바이트가 원본과 같다. 투명 픽셀 아래의 RGB 값도 보존한다. Godot import UID와 기존 압축·알파·크기 설정은 유지했다.

원본 경로·변환 경로·파일/픽셀 SHA-256은 [이미지 manifest](../assets/image_optimization_manifest.json)에 있다. 재검증에는 `tools/requirements-images.txt`를 설치한 Python과 아래 명령을 사용한다.

```powershell
python tools/optimize_images.py --verify --backup-root "<외부 격리 폴더>/original_images"
```

소스 이미지 저장량의 절감 수치다. 기존 Godot 배포 텍스처도 이미 압축되어 있으므로 게임 다운로드의 절감률과 같지 않다. 향후 추가 PNG를 변환할 때는 `--apply --backup-root ...`로 백업·검증하고, 해당 파일을 사용하는 경로와 생성 기록을 함께 갱신한다.

## 격리 위치와 복원

이번 정리의 외부 폴더는 프로젝트와 같은 상위 디렉터리의 `rectangle_game_quarantine_2026-11-10`이다. 프로젝트 내부의 격리 폴더를 만들어 용량을 중복 계산하지 않는다.

- `files/`: 기존 상대 경로를 유지한 구형 자산, 빌드, 영상 제작 산출물·소스, 검수 스크린샷 및 불필요한 작업 자료.
- `original_images/`: 최적화 전 PNG와 원래 `.import` 설정 66쌍.
- `quarantine-manifest.json`: 기존 작업 자료까지 포함한 전체 이동 목록과 SHA-256.
- `verification/`: 이번 테스트·내보내기 검증 로그.

격리한 파일 278개의 합계는 221,219,587바이트다. 프로젝트의 [격리 manifest](QUARANTINE_MANIFEST.json)에는 그중 이전에 Git이 추적하던 파일만 기록했다. 이전부터 있던 별도 작업 첨부파일의 이름이나 내용은 Git에 추가하지 않았다.

복원할 때는 manifest의 `archive_path`에서 필요한 파일만 원래 `path`로 복사하고 SHA-256을 확인한다. 현재 파일을 덮어쓰지 않는다. 이미지 원본을 복원하려면 이미지 manifest의 `original_path`와 현재 `path`를 구분한다. 실행에는 현재 WebP를 사용하므로 구형 PNG나 영상 제작 원화를 모두 복원할 필요는 없다.

오프닝 MP4·WAV·자막과 `tools/opening` 제작 소스도 같은 경로 구조로 외부에 보존했다. 제작을 재개할 때 관련 원화와 함께 복원한다. 게임 재생에 필요한 `assets/video/quadrilateral-opening.ogv`, 포스터와 귀향 장면의 행성 이미지는 저장소에 남아 있다. 제삼자 라이선스와 생성 프롬프트도 보존한다.

## 빌드와 Git

`build/`, `output/`, `tmp/`는 재생성되는 로컬 자료로 Git에서 제외한다. 게임은 [배포 안내](DEPLOYMENT.md)의 소스 빌드 경로로 배포한다. 웹·Windows 패키지는 CI artifact나 Release에 보관한다. 빌드를 실행하면 해당 결과물만큼 로컬 디스크 사용량은 다시 늘어난다.

`tools/font_sources/korean_font_full.ttf.xz`는 한글 폰트를 만드는 필수 입력이므로 유지한다. `.godot/` 캐시는 Git에서 제외한다. 새 체크아웃에서 폰트 캐시가 만들어지기 전 발생하는 정확한 초기 로딩 오류는 한 번만 재시도하며, 이후 import와 테스트는 오류·경고가 있으면 실패한다.

기존 Git 커밋 이력과 원격 저장소는 이번 정리에서 재작성하지 않았다. 추적 중단과 `.gitignore` 추가는 과거의 큰 바이너리를 제거하지 않으므로 기존 `.git` 용량은 남는다. 전체 이력 정리는 별도 백업, 커밋 ID 변경 및 협업자 재클론을 포함하는 별도 작업이다.

## 패키지 검증

아래 크기는 리소스 분리 전 패키지를 보존 기준으로 검증한 기록이다. 이후 웹 초기 다운로드를 약 18.2MB로 줄인 기능별 팩·Brotli 구현과 최신 검증 결과는 [웹 리소스 전달](WEB_DELIVERY.md)에 기록한다.

정리한 Git 파일만 별도 디렉터리에 복원하고 공용 빌더로 웹·Windows 패키지를 생성했다. 새 폰트 캐시의 제한적 초기화 재시도와 그 뒤의 엄격한 import 검사가 실제로 통과했다.

- 웹 결과물: 55.04MB, Windows 결과물: 44.26MB.
- 실제 배포 텍스처 86개를 모두 유지했다. 66개 `.ctex`는 이전과 바이트가 같고, 나머지 20개도 디코딩한 RGBA와 크기가 같다.
- 오프닝 OGV는 이전과 바이트가 같다.
- 패키지에 격리 파일·도구·감사용 manifest가 없고, 웹 결과물에 `.import` 파일이 없다.
- 소스 폴더 밖에서 Windows PCK를 직접 읽어 홈→그림→건축→우주선→공방→월드 진입을 검사했다. 오류·경고 없이 통과했다.
- Godot 전체 검사 15,519개, 웹 로딩 검사 8개, 빌드 초기화 검사 10개가 모두 통과했다. 최종 Godot import·전체 테스트·패키지 실행에 오류·경고가 없다.

실행 자산은 이미 압축되어 있어 배포 파일의 추가 절감은 약 0.18MB다. 원본 이미지와 Git 추적 파일의 절감률을 게임 다운로드 절감률로 해석하지 않는다. 로그와 패키지 비교 보고서는 외부 격리 폴더의 `verification/`에 있다.

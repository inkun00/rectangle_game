# 기본 건축 자재 44종과 주문 제작

기본 40종에 직사각형 평평한 지붕 2종과 **왼쪽·오른쪽 두 각이 직각인 사다리꼴 지붕 2종**을 더했다. 다섯 대표 모양에 각각 8종 이상 배정했다. 대표 모양은 자재를 찾기 위한 분류이며, 수학의 포함 관계는 그대로다. 정사각형은 직사각형·마름모이면서 평행사변형·사다리꼴이기도 하다. 실제 판정은 항상 네 꼭짓점에서 도출한다.

각 모양에는 세 종류 이상의 용도와 서로 다른 길이가 있다. 격자 **1칸은 논리 좌표 20**이며 실제 미터 단위가 아니다. 폭·높이와 빗변 길이는 구별한다. 카드에는 폭·높이, 툴팁과 선택 정보에는 네 변 길이를 표시한다.

기존 18종의 가격과 형상은 유지했다. ‘신규’ 22종은 기존 공개 가격을 게임의 기하면적 비율로 환산하고 100원 단위로 반올림한 가공 추정가이며, 실제 재질별 판매가·맞춤 규격 견적이 아니다. 큰 정사각형 벽돌 벽체는 실제 벽돌 500원×8장으로 계산한다. 원래 가격 출처는 [가격 기준](CONSTRUCTION_PRICES.md), 개별 계산 설명은 게임의 ‘재료 가격의 근거’에 있다.

## 조립과 찾기

- ‘대표 모양’과 ‘용도’를 함께 골라 필요한 자재를 찾는다. 도형의 성질을 만족하는 자재를 모두 표시하므로 직사각형 필터에도 정사각형 재료가 포함된다. 모양을 지정하면 벽돌 한 장/묶음 선택은 접으며, 전체 모양에서는 기존 벽돌 선택을 사용한다.
- 마름모 창은 장식 스티커가 아닌 실제 빈 공간이다. 같은 크기의 마름모 구조 블록으로 네 변을 둘러 바닥까지 이어야 한다. 큰 창과 작은 창 모두 실제 중력·네 변 지지 검증을 거친다.
- 사다리꼴·평행사변형 보와 지붕은 실제 평행한 변 위에 지지한다. 장식은 구조 벽에 붙이며 지붕 하중을 대신 받치지 않는다.
- 벽돌 2·8·9장 묶음은 생성한 단일 벽돌 이미지를 실제 장수대로 반복 표시한다. 석재·콘크리트 벽체는 벽돌 장수에 넣지 않는다.

추가 재질은 [ImageGen 제작 기록](../assets/generated/revision/GENERATION.md)의 `construction-materials-expanded.png`를 사용한다. 기하·충돌·가격·저장 데이터는 이미지 외형과 독립이다.

## 주문 제작과 내 자재

재료 상자의 **주문 제작**에서 다섯 사각형, 가로·세로 크기, 재질, 무늬와 용도를 고른다. 사다리꼴은 기존 모양과 왼쪽·오른쪽 직각 모양을 지원한다. 크기는 0.5칸 간격으로 가로 0.5~30칸, 세로 0.5~20칸이며 정사각형은 두 길이를 함께 조절한다. 마름모의 가로·세로는 두 대각선의 길이이고 실제 변 길이는 별도로 표시한다.

재질은 나무·벽돌·돌·콘크리트·금속, 무늬는 민무늬·줄무늬·격자무늬·마름모 무늬다. 용도는 벽체·지붕·받침보·꾸밈판이며 꾸밈판은 하중을 받치지 않는다. 벽돌 질감을 골라도 임의 크기의 한 조각을 벽돌 장수로 환산하지 않는다. 기존 생성 원화 위에 도형 안으로 제한한 무늬를 표시하므로 견본·도면·회전·시공 검사·완공 기록·PNG에서 같은 외형을 사용한다.

등록은 무료이고 **한 개를 놓을 때마다 제작비를 예약**한다. 지우기·되돌리기는 기존 자재와 같은 방식으로 비용을 돌려주며, 의뢰 정산에서 한 번 지불한다. 나만의 집은 저축에서 사용한 자재비를 뺀 금액을 표시한다. 등록 설계는 배치를 되돌려도 남고, 내 자재 필터로 찾아 의뢰 집과 나만의 집에 반복 사용한다. 같은 선택은 중복 등록하지 않으며 최대 64종을 보관한다.

저장에는 선택값으로 만든 버전 식별자와 등록 목록을 포함한다. 가격과 질량은 식별자에서 재계산하고, 실제 형상은 각 부품의 네 꼭짓점으로 검증한다. 이전 저장에는 빈 등록 목록을 적용한다. 현재 도면·나만의 집·완공 기록에 사용된 주문 자재가 등록 목록에 없거나 잘못된 선택값이 있으면 등록 목록·도면·장부 전체를 변경하지 않는다. 구체적인 게임 단가와 계산 방법은 [가격 기준](CONSTRUCTION_PRICES.md)의 주문 제작 항목을 참고한다.

## 배치한 자재의 자유 회전

배치한 자재를 클릭해 선택한 뒤 가장자리 또는 바깥쪽 둥근 회전 손잡이를 끈다. 가운데 드래그는 기존처럼 이동한다. 회전 중 실제 각도를 표시하며 Shift는 화면 수평선을 기준으로 15° 단위에 맞춘다. 우클릭·Esc는 미완료 회전을 취소하고 화면 이동 모드로 전환한다. 꾸밈판처럼 기존 벽과 겹쳐 배치할 수 있는 자재를 고른 상태에서는 선택 도구로 기존 자재를 선택한다.

미리보기는 원래 네 꼭짓점의 회전 복사본이다. 놓을 때 모델이 건축 범위·겹침·사각형 종류·원래 치수를 검사하고 한 개의 되돌리기 명령으로 확정한다. 잘못된 각도는 붉게 표시하고 놓아도 원래 설계를 유지한다. 자재 수량·제작 단가·크기·질량은 회전으로 바뀌지 않으며 기존 네 꼭짓점 저장 형식을 그대로 사용한다. 시공 검사와 PNG에는 같은 확정 형상을 사용하고 편집 손잡이는 포함하지 않는다.

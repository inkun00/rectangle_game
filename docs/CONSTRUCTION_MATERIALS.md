# 건축 자재 40종

다섯 대표 모양에 **각 8종씩** 배정했다. 대표 모양은 자재를 찾기 위한 분류이며, 수학의 포함 관계는 그대로다. 정사각형은 직사각형·마름모이면서 평행사변형·사다리꼴이기도 하다. 실제 판정은 항상 네 꼭짓점에서 도출한다.

각 모양에는 세 종류 이상의 용도와 서로 다른 길이가 있다. 격자 **1칸은 논리 좌표 20**이며 실제 미터 단위가 아니다. 폭·높이와 빗변 길이는 구별한다. 카드에는 폭·높이, 툴팁과 선택 정보에는 네 변 길이를 표시한다.

기존 18종의 가격과 형상은 유지했다. ‘신규’ 22종은 기존 공개 가격을 게임의 기하면적 비율로 환산하고 100원 단위로 반올림한 가공 추정가이며, 실제 재질별 판매가·맞춤 규격 견적이 아니다. 큰 정사각형 벽돌 벽체는 실제 벽돌 500원×8장으로 계산한다. 원래 가격 출처는 [가격 기준](CONSTRUCTION_PRICES.md), 개별 계산 설명은 게임의 ‘재료 가격의 근거’에 있다.

## 조립과 찾기

- ‘대표 모양’과 ‘용도’를 함께 골라 필요한 자재를 찾는다. 대표 모양을 지정하면 그 모양의 8종을 모두 표시하며 벽돌 한 장/묶음 선택은 접는다. 전체 모양에서는 기존 벽돌 선택을 사용한다.
- 마름모 창은 장식 스티커가 아닌 실제 빈 공간이다. 같은 크기의 마름모 구조 블록으로 네 변을 둘러 바닥까지 이어야 한다. 큰 창과 작은 창 모두 실제 중력·네 변 지지 검증을 거친다.
- 사다리꼴·평행사변형 보와 지붕은 실제 평행한 변 위에 지지한다. 장식은 구조 벽에 붙이며 지붕 하중을 대신 받치지 않는다.
- 벽돌 2·8·9장 묶음은 생성한 단일 벽돌 이미지를 실제 장수대로 반복 표시한다. 석재·콘크리트 벽체는 벽돌 장수에 넣지 않는다.

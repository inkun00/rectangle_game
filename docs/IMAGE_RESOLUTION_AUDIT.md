# 이미지 해상도 검수

2026-11-01. 기존 비트맵 **136개**와 SVG **21개**의 원본 크기·배포 포함 여부·사용처를 조사했다. 큰 화면의 배경은 파일 전체의 크기만 보지 않고 실제 잘라 쓰는 영역의 크기로 판단했다. [전체 목록과 생성 파일 실측값](IMAGE_RESOLUTION_AUDIT.json), [원화·프롬프트](../assets/generated/starfront-hd/GENERATION.md).

총 **22개 생성 파일**이 9개 배경·20개 환경물·23개 재료 표면을 제공한다. 원본 PNG를 이미지 편집 라이브러리로 늘리지 않았다. Python 검수 도구는 크기·출처·해시와 배포 포함 여부만 읽어 JSON을 작성한다.

검수 기준은 실제 1920×1080 및 800×600 실행 화면이다. 생성기가 반환한 실제 원본은 위 표의 크기이며 4K 원본이라고 표시하지 않는다. 더 큰 디스플레이에서 추가 확대가 발생할 수 있다. 픽셀 아트의 작은 네모 결은 유지하되, 작은 셀을 여러 배 확대하던 문제를 줄였다.

실행 검수: 지역 6곳, 홈, 그림, 건축, 공방, 학습, 가방, 대화창에서 구도·톤·선명도·투명 여백·잘림을 확인했다. 같은 1920×1080 화면에서 구 배경과 새 배경을 바꿔 비교했다. 기존 수학 정의·네 꼭짓점·아이템/재료 ID·저장 형식은 바꾸지 않았다.

재현 명령: `python tools/audit_image_resolution.py`, `powershell -File tools/run_tests.ps1`.

검증 결과: Godot 전체 검사 9,523개 통과, 오류·경고 0건. 웹 로딩 셸 검사 8개 통과. 별도 브라우저 세션에서 홈→공방→예시 조립→월드→가방을 실행했고 콘솔 오류가 없었다. 고해상도 원화가 포함된 게임 데이터는 gzip 약 48.5MiB이며 이전보다 초기 다운로드가 커졌다.

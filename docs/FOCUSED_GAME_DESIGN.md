# 작품에 집중하는 게임 화면

사용자가 지적한 낮은 해상도의 큰 테두리, 도면과 맞지 않는 원근 배경, 겹치는 장식 문제를 해결하기 위한 참고 조사입니다. 아래 ‘관찰’과 ‘적용’은 공식 화면을 보고 내린 이 프로젝트의 디자인 해석이며, 원작 개발자의 설계 의도를 단정하지 않습니다.

Wilmot와 Dorfromantik의 링크된 스크린샷은 원본을 열어 시각적으로 확인했습니다. Townscaper는 공식 설명과 기능을 참고했으며 플레이 검증을 했다는 의미는 아닙니다. 원작의 그림·UI·코드는 프로젝트에 복사하지 않습니다.

## 적용 기준

1. **도면의 기준은 실제 기하 좌표입니다.** 격자·치수·바닥선·재료는 같은 좌표 변환으로 움직입니다. 정면 도면 뒤에 원근감 있는 공사장 풍경을 겹치지 않습니다.
2. **큰 화면은 조용한 바탕으로 둡니다.** 작은 장식용 패널이나 버튼 그림을 화면 전체로 확대하지 않습니다. 생성 그림은 썸네일·재료·인물 등 의미가 있는 영역에 두고 비율과 경계를 지킵니다.
3. **시각적 우선순위를 제한합니다.** 작품이 중심, 현재 도구와 주요 행동이 그다음, 조작 안내와 보조 정보가 마지막입니다. 굵은 파랑·금색 테두리를 모든 요소에 반복하지 않습니다.
4. **메인은 선택을 돕습니다.** 그림 그리기·집 짓기·모험을 구분하고 각 버튼이 무엇을 시작하는지 명확히 표시합니다. 카드와 이미지의 경계는 일치시키고 화면 밖으로 이어지는 큰 배경 프레임을 없앱니다.

재료·의뢰·비용·저장·물리 검사의 규칙은 유지합니다. 새 그림이 필요한 경우에는 프로젝트의 생성 이미지와 제작 기록을 사용하며, 참고 게임의 에셋을 배포물에 포함하지 않습니다.

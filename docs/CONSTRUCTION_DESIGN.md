## 화면 구성

- 상단: 프로젝트 이름·사무소 잔액, 의뢰 확인 → 입면 설계 → 시공 검사 → 납품·정산.
- 왼쪽: 질감 견본이 있는 자재 카드, 재료 종류 필터, 한 장/9장 묶음 선택.
- 중앙: 제도 도면과 재료 보기, 선택·편집 도구, 안내와 중력 검사.
- 오른쪽: 의뢰 조건·공사 견적·예산 사용량·선택 자재의 도형 포함 관계.
- 좁은 화면: 의뢰·장부는 상단 버튼으로 열어 작업 공간을 확보한다.
- 대화창: 문서 내용은 스크롤하고 계약·납품·복귀 행동은 아래쪽에 고정한다. 열린 상태에서 창을 줄여도 행동 버튼이 화면 안에 남도록 본문 높이를 다시 계산한다. Tab·방향키 포커스는 대화창 내부에서 순환하며, 스크롤 목록은 키보드로 고른 항목을 보여 준다.
- 완공 기록: 독립된 읽기 전용 문서의 입면 미리보기, 만족도와 수익을 표시한다. 최근순으로 여섯 채씩 페이지를 나눈다.

자재 견본과 실제 건물의 질감은 ImageGen으로 생성한 PNG를 원래 네 꼭짓점에 맞춰 표시한다. 재료의 실제 충돌 영역·가격·도형 종류는 시각 표현에 의해 바뀌지 않는다. 치수의 단위는 게임 격자인 **칸**이며 한 칸은 논리 좌표 20이다. 화면의 칸을 현실의 미터로 환산하지 않는다. 40종 자재 카드에 폭·높이를, 선택 자재와 설명에 실제 네 변의 길이를 표시한다. 의뢰의 길이 조건도 같은 꼭짓점에서 계산하여 회전에 영향을 받지 않는다.

자재는 대표 모양별 각 8종이며 ‘도형별’ 찾기와 용도 필터를 교차한다. 이는 선택 편의를 위한 대표 모양 분류이고 수학의 포함 관계와 다르다. 대표 모양을 고르면 해당 모양의 8종을 모두 표시하고, 사용자가 필터를 바꾸면 첫 자재부터 보여 준다. 높이가 작은 화면에서는 용도 칩을 드롭다운으로 바꾸어 자재 카드 전체가 보이게 한다. 첫 집 안내가 다음 자재를 선택할 때 숨겨진 필터는 해제하고 해당 항목으로 스크롤한다. [전체 자재](CONSTRUCTION_MATERIALS.md)에 용도와 규격을 기록한다.

설계 보기의 눈금·격자·선택 표시와 재료 보기는 문서·Undo/Redo·물리 상태를 수정하지 않는다. 읽기 전용 보기에서는 선택 핸들을 숨긴다. 모든 편집은 기존 명령 기록을 사용한다.

`기초 배치 도움`은 빈 작업대에서는 바로 예시를 놓는다. 이미 재료가 있으면 현재 설계를 예시로 바꾼다는 설명과 취소 버튼을 먼저 제공한다. 교체 후에도 되돌리기로 원래 설계를 복원할 수 있다.

패널·아이콘·자재 질감·의뢰인·메인 표지는 내장 ImageGen 생성 PNG를 사용한다. 기존 모험의 ImageGen 자산도 유지한다. 출처와 정확한 프롬프트는 [이미지 교체 기록](../assets/generated/revision/GENERATION.md), 이전 제작 자료는 [CONSTRUCTION_ASSETS.md](CONSTRUCTION_ASSETS.md)에 있다.

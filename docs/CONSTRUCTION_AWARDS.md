# 건축 명예의 전당과 이미지 배지

이 평가는 AI가 그림의 아름다움을 추측하는 평가가 아니라, 실제 사각형 꼭짓점에서
계산하는 게임용 설계 기준이다. 다른 모양의 집도 자유롭게 지을 수 있으며 점수는
건축비·보너스·학습 과제의 필수 조건을 대신하지 않는다.

3단계 이상에서 현재 설계의 시공 검사와 필수 조건, 예산 검사를 모두 통과한 집만
수상 대상이다. 빈 설계, 겹친 중복 자재, 잘못된 사각형, 외벽에 빈틈이 있는 집과
실패하거나 오래된 검사 결과는 배지를 받을 수 없다. 수상 기록은 집을 전달할 때
완성 기록에 보관한다. 저장본을 읽을 때 점수와 배지, 평가 항목을 다시 계산하여
고쳐 쓴 수상 정보를 거부한다. 과거 완료 기록에는 새 배지를 임의로 지급하지 않는다.

| 평가 항목 | 최대 | 실제 도형에서 계산하는 기준 |
|---|---:|---|
| 집의 비례 | 20 | 외벽 경계의 가로÷세로가 1.2~3.6이면 20점. 범위 밖에서는 비율에 따라 감소 |
| 문과 창의 비율 | 20 | 문·창의 실제 넓이 합이 외벽 경계 넓이의 12~45%이면 20점. 범위 밖에서는 비율에 따라 감소 |
| 문과 창의 좌우 배치 | 20 | 문·창의 넓이로 가중한 중심과 외벽 중심의 가로 차이가 외벽 폭의 2.5% 이내이면 20점. 차이가 25%에 이르면 0점 |
| 도형과 재료의 조합 | 20 | 실제로 고른 도형 종류당 3점, 재료 표면 종류당 2점. 각각 최대 4종. 같은 종류를 반복해도 추가 점수 없음 |
| 지붕과 처마의 마감 | 20 | 지붕 중심과 외벽 중심의 일치 8점, 양쪽 처마 10~80단위 8점, 지붕 높이 20단위 이상 4점. 평평한 지붕도 만점 가능 |

수학의 포함 관계와 구분하여, 재료 조합에서는 사용자가 **고른 종류**를 센다.
정사각형 하나가 정사각형·직사각형·마름모·평행사변형·사다리꼴 다섯 종류를 썼다는
뜻은 아니다. 도형의 수학적 성질을 설명할 때는 기존의 포함 관계를 그대로 따른다.

| 등급 | 기준 | 이름 |
|---:|---:|---|
| 1 | 60점 이상 | 좋은 설계상 |
| 2 | 70점 이상 | 빛나는 설계상 |
| 3 | 80점 이상 | 훌륭한 건축상 |
| 4 | 90점 이상 | 명예 건축가상 |
| 5 | 97점 이상 | 최고 건축 대상 |

이미지는 `ConstructionExporter.export_png`로 1200×800 PNG를 만든다. 사용자가 지은
네 꼭짓점 도형과 자재 질감, 종이 바탕만 그린다. 격자·자·치수·선택 표시·UI
글자는 들어가지 않는다. 검증된 완료 기록의 배지가 있으면 해당 생성 PNG를 왼쪽
위에 합성하며, 미완성 설계와 배지가 없는 과거 기록에는 배지를 붙이지 않는다.
원본 자재와 집의 기하 정보는 PNG 내보내기로 변경되지 않는다.

수상 로직: `scripts/construction/construction_awards.gd`.
원본 배지와 생성 출처: `assets/generated/construction-game/GENERATION.md`.

사다리꼴·평행사변형·마름모·직사각형·정사각형의 포함적 분류는 수학 계산의 일관성을 위해 유지한다. 학생 화면에서는 실제 성질을 묻고 해당하는 도형을 모두 허용한다. 지도서 209~210쪽의 교사 배경 내용에 있는 포함 관계 계통도를 학생의 암기 목표로 삼지 않는다. 240~243쪽처럼 성질에 따라 정사각형도 정답이 되는 경우를 자연스럽게 허용한다.

길이는 실제 화면의 cm가 아닌 **그림 속 1칸 = 모델 좌표 20단위**이다. 반올림한 길이·각에는 ‘약’을 붙인다. 그림과 표시는 동일한 네 꼭짓점에서 유도한다. 6칸인 마름모 등불의 네 변을 더하는 활동은 같은 네 변의 성질을 활용한 덧셈이며 별도의 둘레 공식이나 넓이 공식을 가르치지 않는다. 사각형의 볼록성·비퇴화·각의 합 360°는 내부 검증에도 사용한다.

집 짓기 도형 필터·신규 의뢰의 도형 조건도 실제 성질을 사용한다. 예를 들어 네 직각을 갖는 정사각형 창은 직사각형 조건을 충족한다. 재료의 용도와 품목 이름은 상품 정보이며 수학적 배타 분류를 뜻하지 않는다. 과거 버전 5 이하 저장의 정산 규칙은 기존 수입·진행을 보존하기 위해 당시 버전으로 검증한다.

학습은 전투·레벨·건축 자산과 무관하게 접근한다. 모험에는 전투 피해 끄기와 여러 손가락으로 이동·점프하는 화면 버튼을 제공한다. 활동 기록은 익명 로컬 기록이며 학습 효과나 숙달을 자동 판정하지 않는다.

# 대화로 따라 하는 모드 안내

각 모드를 처음 열면 안내원 직각이가 한 번에 한 가지 조작을 안내한다. 설명 단계에서는 배경을 어둡게 하고 편집·이동 입력을 막는다. 실습 단계에서는 화면을 다시 조작할 수 있고, 필요한 버튼이나 작업 영역을 표시한다. 실제 행동이 확인되어야 다음 단계로 넘어간다.

| 안내 | 직접 해 보는 조작 |
| --- | --- |
| 수학 직접 해 보기 | 재어 보기 → 선 조절 또는 도형 선택 → 확인하기 |
| 자유 그림 | 도형 놓기 → 이동·크기·방향 편집 → 되돌리기 |
| 명화 채우기 | 밑그림 선택 → 표시·진하기 변경 → 사각형 놓기 |
| 부탁받은 집 짓기 | 부탁 읽고 수락 → 재료 놓기 → 튼튼한지 검사 |
| 나만의 집 | 재료 놓기 → 재료 보기로 집 모습 살펴보기 |
| 캐릭터 공방 | 골격 한 칸 채우기 → 모든 칸 완성 |
| 모험 첫걸음 | 걷기 → 점프 → 가방 열고 닫기 → 부탁 수첩 열고 닫기 |

‘건너뛰기’ 또는 Esc로 즉시 종료한다. 완료·건너뛰기 기록이 있는 안내는 자동으로 다시 열리지 않는다. 진행 중 모드를 나가면 안내만 취소하며, 미완료 안내는 다음 방문에 다시 볼 수 있다.

홈의 **모드 안내**에서 일곱 안내를 고를 수 있다. 수학·그림·공방은 **튜토리얼**, 건축은 **도움말 → 대화로 따라 해 보기**, 월드는 **모험 메뉴 → 튜토리얼 다시 보기**로 다시 시작한다. 아직 캐릭터를 완성하지 않았다면 모험 안내에 앞서 공방 안내로 연결하며 월드 진입 조건을 우회하지 않는다.

## 기존 작품과 학습 기록

안내 자체는 예시 캐릭터를 만들거나, 집을 수락하거나, 물건을 구매하거나, 파일 다운로드를 시작하지 않는다. 기존 작품을 초기화하지 않는다. 사용자가 안내를 따라 한 편집에는 원래의 명령·되돌리기·자동 저장을 그대로 적용한다.

이미 채운 골격, 고른 밑그림, 배치한 건축 재료, 완료한 집, 확인을 마친 수학 활동은 해당 작업을 다시 강요하지 않는다. 수학의 정답·까닭과 집의 검사 결과는 기존 규칙으로 판단한다. 튜토리얼의 조작 확인만으로 학습 완료·코인·XP를 지급하지 않는다.

별도 `user://quadrilateral_tutorial_v1.json`에 버전과 모드별 `completed`/`skipped`만 저장한다. 월드·그림·집·학습 저장 형식은 유지한다. 파일을 검증한 후 일괄 적용하며 잘못된 데이터는 현재 상태를 바꾸지 않는다. `app.testing=true`는 자동 안내와 실제 사용자 안내 기록의 읽기·쓰기를 끈다.

가방·수첩·그림 선택창·색 선택창이 열리면 안내가 입력을 양보한다. 창을 닫아야 다음 대화가 이어진다. 월드 안내 중에는 접촉 피해를 막고, 끝난 뒤 원래의 편안한 탐험 설정으로 돌아간다. 대화를 넘길 때 누른 Space·Enter는 점프 실습으로 처리하지 않는다.

## 구현과 검증

`scripts/tutorial/tutorial_catalog.gd`는 대사·행동·대상 ID, `tutorial_progress.gd`는 독립된 안내 기록, `tutorial_director.gd`는 실제 모델·입력 신호와 단계 전환, `scenes/ui/tutorial_overlay.gd`는 대화·강조·스킵 UI를 담당한다. 수학 도형과 플레이어 작품의 렌더링은 기존 코드가 담당한다. 새 원화를 추가하지 않고 기존 생성 인물과 UI 프레임을 사용한다.

진행 기록의 검증·저장 왕복과 7개 모드의 실제 조작, 스킵·다시 보기, 기존 작품 보존, 창 입력 소유권, 작은 화면·큰 화면을 자동 검사한다. 별도 테스트 세션에서 1366×768 및 800×600의 31개 실행 화면으로 한글·버튼·작업 영역을 검수했다.

검증 결과: 전체 Godot 검사 **10,288개 통과**, 오류·경고 0건. 웹 로딩 셸 검사 8개 통과. 브라우저의 독립 세션에서 그림의 자동 안내→추가→이동→되돌리기→완료→다시 보기→건너뛰기→새로고침 후 재진입을 실행해 작품과 안내 기록 보존을 확인했다. 공방에서 월드로 들어가 실제 키보드 걷기·점프·가방·수첩과 마지막 대화까지 완료했으며 콘솔 오류가 없었다. Web/Windows 내보내기도 성공했다.

재현: `powershell -File tools/run_tests.ps1`, `powershell -File tools/export_web.ps1`, `powershell -File tools/export_desktop.ps1`.

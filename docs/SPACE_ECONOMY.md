# 그림 판매와 사각형 우주선 제작

그림 판매 수익, 건축 의뢰 이익, 마을 심부름 보상을 한 장부에 모아 지구에서 살 집이나 귀향 우주선을 만든다.
금액은 게임 안의 가상 원화 예산이며 실제 우주선 부품 가격이나 시장 견적이 아니다.

## 하나의 저축 장부

새 진행 기록은 기존 `ConstructionState`의 건축 저장에 선택 필드로 보관한다.
`art_sales`는 판매한 작품과 수익, `purchased_ship_parts`는 구매한 부품,
`design`은 구입한 부품의 모양·색 선택이다. 기존 저장의 부품은 기본 모양을 사용한다.
마을의 `village_rewards`에는 제작 자금을 지급한 부탁 ID를 보관한다. 코인은 기존대로 상점과 여관에서 사용하고, 각 부탁은 코인 보상 수에 300만 원을 곱한 제작 자금도 한 번 지급한다. 16개 부탁의 제작 자금은 총 14억 8,500만 원이다.

저축 계산은 다음과 같다.

```text
저축 = 처음 운영 자금 30,000,000원
     + 완료한 건축 의뢰의 누적 이익
     + 그림 판매 누적 수익
     + 마을 심부름 제작 자금
     - 구매한 우주선 부품의 총액

우주선에 쓸 수 있는 돈 = max(0, 저축 - 내 집에 사용한 자재비 - 30,000,000원)
```

건축 의뢰의 선금은 맡아 둔 공사비이므로 우주선 구매에 쓸 수 없다. 최소 운영
자금 3천만 원과 현재 내 집 자재비를 남겨, 우주선을 만들다가 기존 집이나 다음
첫 단계 의뢰를 진행할 수 없게 되는 상황을 방지한다. 이미 완성한 건축 기록의
금액과 보상은 다시 계산해 바꾸지 않는다.

그림 판매와 부품 구매는 후보 장부를 먼저 검증·저장한 후 살아 있는 경제 상태에
반영한다. 저장에 실패하면 수익 지급·부품 구매를 완료로 표시하지 않는다.
다른 화면의 그림이나 건축 Undo/Redo 이력은 경제 거래 때문에 재생성하지 않는다.

## 건축 진행 보존

현재 건축은 **9단계·9가지 의뢰**이며, 단계별 해금 조건은 기존처럼 완료한 건축
실적을 기준으로 한다. 그림 수익으로 과거 건축 단계의 해금 판정을 바꾸거나,
우주선 부품을 샀다는 이유로 이미 달성한 건축 실적을 잃지 않는다. 9단계의 기존
누적 건축 이익 조건은 8천만 원이다.

현재 계약금액은 1억~2억6천만 원이지만 기본 공사비와 자재비를 제외한 이익만
저축에 쌓인다. 따라서 계약금 전체를 우주선 자금으로 취급하지 않는다.

내 집의 자재 예산은 남은 저축과 함께 갱신한다. 부품 구매 뒤, 과거의 비싼 내 집
설계를 Undo/Redo로 복원하려 할 때도 현재 예산을 검사한다. 부족하면 그림·집
수익을 더 모으라는 안내를 표시하고 **도형과 명령 스택은 그대로 보존**한다.
예산이 다시 충분해지면 같은 되돌리기·다시 실행을 할 수 있다.

## 우주선 부품 가격

12개 부품은 모두 네 꼭짓점의 사각형으로 구성한다. 가격은 고향으로 돌아가기
위한 장기 목표가 되도록 다음과 같이 설정한다.

| 부품 순서 | 가격 | 누적 구매액 |
| --- | ---: | ---: |
| 1 | 20,000,000원 | 20,000,000원 |
| 2 | 30,000,000원 | 50,000,000원 |
| 3 | 40,000,000원 | 90,000,000원 |
| 4 | 50,000,000원 | 140,000,000원 |
| 5 | 60,000,000원 | 200,000,000원 |
| 6 | 70,000,000원 | 270,000,000원 |
| 7 | 90,000,000원 | 360,000,000원 |
| 8 | 110,000,000원 | 470,000,000원 |
| 9 | 130,000,000원 | 600,000,000원 |
| 10 | 160,000,000원 | 760,000,000원 |
| 11 | 200,000,000원 | 960,000,000원 |
| 12 | 240,000,000원 | **1,200,000,000원** |

총액은 **12억 원**이다. 처음 운영 자금만으로 부품을 사는 방식이 아니라 실제
수익을 모아야 한다. 모든 부품을 구매하기 전에는 출발할 수 없고, 같은 부품을
중복 구매하거나 출발 처리를 반복해 추가 보상을 얻을 수 없다.

구입한 부품마다 다섯 가지 사각형과 색을 선택할 수 있다. 500만 원을 벌면 홈에서 지구에 남을 집을 선택할 수 있다. 두 엔딩의 완성 PNG와 패들릿 등록 상태는 게시 기록에 보관하며, 엔딩에서는 그 PNG를 직접 움직이거나 배경에 배치한다. 게시를 재시도해도 다시 결제하거나 새 PNG를 만들지 않는다.

## 그림 판매 원칙

판매 대상은 플레이어가 직접 배치한 사각형 작품이다. 배경이나 명화 밑그림만
고른 빈 화면은 판매 대상이 아니다. 작품의 사각형·색·화면 구성 등 확인 가능한
요소로 판매 제안을 만든다. **새 판매**에는 다음 기준을 함께 적용한다.

- 실제로 보이는 사각형 조각이 **6개 이상**이고 도화지의 **12% 이상**을 칠해야 한다.
- 충분히 구별되는 색이 **2가지 이상**이어야 한다. 각 색이 칠한 부분의 **3% 이상**을
  차지해야 하므로 서로 비슷한 색이나 작은 색점만으로는 조건을 채울 수 없다.
- 집·나무·로봇·우주선은 핵심 부품의 상대 위치와 크기로 공간 구조를 확인한다.
  집의 몸체·지붕·문·창문처럼 부품이 형태를 이루어야 한다. 해당 부품이 **실제로
  보이는 그림 넓이의 70% 이상**을 차지해야 하며, 여러 완성된 사물의 부품을
  합산하므로 마을·숲도 인정한다.
- 사물 그림 외에 **크기 변화, 가로·세로 두 축의 정렬, 구획을 갖춘 기하 구성**도
  인정한다. 명화 모드의 몬드리안 같은 구성을 사물 모양이 아니라는 이유로 막지 않는다.

작거나 가려진 조각, 작은 색점, 몸체와 같은 색으로 보이지 않는 문·창문은 조건을
채우는 세부 표현으로 세지 않는다. 단순 나열과 무작위 겹침만으로는 판매할 수 없다.
판매창에는 충족·부족 항목과 가장 가까운 형태의 구성 기준을 완성할 힌트를 표시한다.
화랑은 도형의 배치와 색을 계산해 게임이 정한 구조 기준을 확인한다.

이 강화 기준은 신규 판매 가능 여부에만 적용한다. 과거의 **9필드 영수증**과
도형 5개·넓이 8%를 사용한 기존 영수증 검증, 가격 계산식을 유지하여 이미 지급한
수익과 저장 기록을 보존한다. 판매 확인창에서는 **최대 80자의 작품 제목을 반드시
입력**해야 한다.

판매할 작품을 제목이 포함된 PNG로 자동 저장한다. 설치형 앱의 기본 위치는
운영체제의 **사진(Pictures) 폴더/사각형 월드/판매한 그림**이다. 웹에서는 브라우저의
PNG 다운로드를 시작하고 같은 사이트의 `user://` 저장소에도 파일을 보관한다.
같은 제목으로 판매해도 기존 PNG를 덮어쓰지 않도록 서로 다른 파일명을 사용한다.

저장과 거래가 성공한 뒤 도화지를 초기화하고 **빈 종이·자유 그림 모드**로 새 작품을
시작한다. 저장이나 거래가 실패하면 현재 도형·배경·그리기 모드를 유지한다.
판매 이후 Undo로 이전 작품을 복원해도 지급된 수익과 판매 기록은 되돌리지 않는다.

선택한 도형 ID, 레이어 선택, 저장 시점 같은 편집 상태는 새 작품의 근거가 아니다.
판매 기록은 작품 내용으로 중복을 확인하여 같은 작품을 다시 불러오거나 Undo로
되돌려도 같은 수익을 반복 지급하지 않는다. 제목을 바꾸는 것만으로도 새 판매가
되지는 않는다. 작품 제목, 판매 가격과 작품 식별 정보·평가값을
장부에 보관하여 다시 불러왔을 때 검증할 수 있게 한다.

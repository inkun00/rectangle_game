# 공방과 모험 UI 개선

기존 생성 그림의 양피지·남색·초록색 분위기와 Noto Sans KR을 유지하면서, 작은 창에서 읽고 조작하기 어려운 부분을 개선했습니다. 캐릭터의 꼭짓점과 월드 좌표, 퀘스트·저장 규칙은 바꾸지 않습니다.

| 이전 | 변경 | 목적 |
| --- | --- | --- |
| 월드와 함께 축소되는 글자 | UI 전용 화면 배율과 별도 글꼴 래스터 크기 | 좁은 창에서도 선명하게 읽기 |
| 고정 너비의 공방·대화창 | 도구 줄바꿈, 좁은 창 선택 메뉴, 화면 안의 스크롤 | 도구와 닫기 버튼에 항상 접근하기 |
| 마우스 중심의 모험 메뉴 | Tab·Shift+Tab·Enter·Esc, 초점 테두리, 닫은 뒤 초점 복귀 | 키보드로 대화와 메뉴 조작하기 |
| 모든 부탁이 이어지는 목록 | 진행 중·새 부탁·완료·전체 필터 | 현재 해야 할 일 찾기 |
| 빈 가방과 무조건 활성화된 회복 버튼 | 다음 행동 링크, 회복 가능 여부와 이유 | 가능한 행동을 이해하기 |
| 다운로드 완료와 실행 준비가 같은 로딩 표시 | 내려받기·시작 상태 분리, 한국어 안내, 재시도 | 기다리는 상황과 복구 방법 알기 |

적용한 스킬은 UI/UX Pro Max(가독성·초점·빈 상태), Emil Design Engineering(즉시 반응·키보드 흐름), Frontend Design(기존 게임의 시각적 일관성)입니다. Web Design Guidelines는 HTML 로딩 화면에 적용했습니다. Hallmark의 새 페이지 제작 규칙은 기존 Godot 화면 개선 범위에 적용하지 않았습니다.

검증에는 실제 창 크기 800×600, 783×712, 1280×720, 추가 화면 배율, 키보드 입력, 필터별 퀘스트 표시, 회복약 상태를 포함합니다. 공방은 560×860과 375×812에서도 가로 넘침을 확인했습니다. 작은 세로 화면에서의 공방 배치는 지원하지만 게임은 키보드 사용을 전제로 합니다.

# 집 짓기 화면의 게임 참고 자료

확인일: 2026-10-29 (한국 시간). 실제 건축 게임의 공식 소개와 공개 갤러리를 먼저 확인한 뒤, 사각형 월드의 어린이용 화면 방향을 정했다. 아래의 **적용안은 우리 프로젝트의 설계 판단**이며, 해당 게임이 이 배치나 문구를 권장한다는 뜻은 아니다.

## 공개 이미지의 위치

다음은 공식 갤러리에서 확인한 이미지 링크다. 프로젝트 파일로 내려받거나 게임에 넣지 않았다. 이미지 링크를 열어 출처를 확인할 수 있으며, 링크 접근만으로 세부 UI를 픽셀 단위로 검증했다고 간주하지 않는다.

## 화면에 반영할 자체 설계

1. **주인공은 집**: 집을 놓는 공간을 가운데 넓게 확보하고, 돈·기록·도움말은 접거나 별도 창에서 본다.
2. **큰 재료 상자**: 한 카드에 실제 재료 그림, 쉬운 이름, 사각형 종류, 크기, 값을 표시한다. 선택 색은 짙은 파랑과 흰 글자이며, 선택되지 않은 카드는 밝은 크림색과 짙은 글자를 쓴다.
3. **한 번에 한 가지 목표**: 지금 할 일을 단계 카드로 표시하고 다음 행동 버튼을 가까이 둔다. 검사 결과에는 '어느 재료의 어느 변을 받칠지'를 알려 준다.
4. **아이의 말로 설명**: 어려운 건축 용어를 쉬운 말로 바꾼다. 수학의 도형 이름은 유지하고 짧은 설명과 눈에 보이는 도움말 창을 제공한다.
5. **다시 해 볼 수 있는 놀이**: 되돌리기·고치기·미리보기를 쉽게 찾게 한다. 검사 뒤 원래 설계를 고칠 수 있고, 실수 때문에 저장한 집을 잃지 않게 한다.

이 방향은 공식 자료에서 확인한 구성 방식으로부터 도출한 자체 설계다. 특정 게임의 정확한 카드 크기·색상·배치를 그대로 가져온 규격이 아니다.

## 말 바꾸기 감사

코드의 저장 키나 계산은 바꾸지 않고 `scripts/construction/construction_language.gd`에서 **표시되는 문구만** 바꾼다. 가격 출처의 원문·제품명·URL은 근거 자료 화면에 남긴다. 보너스·정보·'마주 보는 변' 같은 다른 단어가 '보' 때문에 잘못 바뀌지 않게 검사한다.

| 기존 말 | 화면의 쉬운 말 |
| --- | --- |
| 자재 라이브러리 / 선택 자재 | 재료 상자 / 고른 재료 |
| 정면 입면도 / 입면 설계 | 집 앞모습 / 집 짓기 |
| 외장 패널 / 외장판 | 꾸미기 판 |
| 받침보 / 보 | 가로 받침 |
| 처마 / 외벽 | 지붕 끝 / 바깥벽 |
| 개구부 | 문·창문 자리 |
| 기초 / 구조재 | 바닥 받침 / 집을 받치는 재료 |
| 하중 / 지지 | 누르는 무게 / 받침 |
| 시공 검사 | 튼튼한지 확인 |
| 견적 / 자재 예산 | 예상 비용 / 재료에 쓸 돈 |
| 계약금 / 계약금액 | 먼저 받는 돈 / 약속한 돈 |
| 정산 / 준공 완료 | 보상 받기 / 집 완성! |
| 의뢰서 / 의뢰인 | 부탁 카드 / 집을 부탁한 사람 |
| 공사 장부 | 집 짓기 돈 기록 |
| 규격 / 벽체 / 모르타르 | 크기 / 벽 묶음 / 벽돌을 붙이는 재료 |

문장은 조사까지 바꾼다. 예를 들어 '보를 놓아요'는 '가로 받침을 놓아요', '시공 검사를 다시 해 주세요'는 '튼튼한지 다시 확인해 주세요'가 된다. 수학의 **사다리꼴·평행사변형·마름모·직사각형·정사각형** 이름은 그대로 쓴다. 사다리꼴의 포괄적 정의와 정사각형의 포함 관계, 평행선 사이 거리를 수직으로 잰다는 설명도 유지한다.

## 출처·권리·도입 범위

| 자료 | 권리 확인 범위 | 프로젝트에 도입한 것 |
| --- | --- | --- |
| 위 네 게임의 공식 웹페이지·갤러리·시연 | 상용 게임의 공개 소개다. 원본 아트·코드의 재사용 허락은 확인하지 않았다. | 출처 링크, 내용을 짧게 요약한 연구 기록, 일반적인 조립·안내·피드백의 설계 판단만 사용한다. |
| 새로 만드는 사각형 월드 그림 | 이 프로젝트의 생성 기록에 프롬프트·도구·파일을 별도로 기록한다. | 우리 게임의 사각형 재료, 배경, 조작 아이콘, 인물과 표면 그림을 만든다. 타 게임 스크린샷·로고·캐릭터를 생성 입력이나 배포 파일로 넣지 않는다. |

이 문서는 제3자 게임의 라이선스를 사각형 월드 코드에 적용하는 문서가 아니다. 기존 Kenney CC0와 Godot MIT 등 프로젝트의 개별 출처·라이선스 문서는 계속 보존한다.

# 별빛 개척지 화면 개편

2026-11-01. 사용자가 요청한 Starbound의 분위기를 우리 사각형 학습 게임에 적용했다.

## 조사 범위와 근거

- [Starbound 공식 Steam 페이지](https://store.steampowered.com/app/211820/Starbound/?l=koreana)의 공식 스크린샷과 소개를 확인했다. 밝은 작업등과 어두운 풍경, 목재 정착지와 우주 배경, 겹쳐 보이는 원경·건물·작은 캐릭터가 주요 시각적 참고점이다.
- 사용자가 지정한 [REA 한국어 안내](https://github.com/morluto/rea/blob/main/docs/readme/README_ko.md)를 읽고 연결된 REA의 `capture_browser_scenario`로 공식 Steam 페이지를 실제 열었다. Chromium 156, 1440×900, 한국어 로케일에서 DOM·최종 URL·네트워크 이벤트를 관찰했다. 일부 네트워크 이벤트가 관찰 종료 시점에 완료되지 않아 전체 캡처는 incomplete로 기록됐다. 페이지 구조 관찰을 게임 내부 동작의 증거로 사용하지 않았다. 요약 Evidence는 [STARBOUND_REA_EVIDENCE.json](STARBOUND_REA_EVIDENCE.json)에 기록했다.
- 기본 Steam 경로에서 게임 설치본을 찾지 못했다. 따라서 실행 파일, `.pak` 내용, 게임 내부 클래스·렌더러·현재 런타임을 분석했다는 주장은 하지 않는다. REA로 관찰한 대상은 Steam 웹페이지다. 지역 배경·UI 계층에 관한 적용안은 공개 화면을 바탕으로 한 설계 판단이다.
- [Silverfeelin의 공개 UI 모드 문서](https://github.com/Silverfeelin/Starbound-ManipulatedUI)는 이미지·라벨·버튼을 설정으로 정의하고 스크립트 콜백과 구분하는 실제 모드 작성 예시다. 오래된 모드의 작성자 자료이며 Starbound 엔진 전체의 명세로 일반화하지 않았다. 코드·그림은 복사하지 않았다.

## 우리 게임의 화면 구조

| 계층 | 새 표현 | 구현 |
| --- | --- | --- |
| 공간 | 여섯 지역별 픽셀 풍경, 행성·황혼·오로라·정착지 | `WorldArtwork`의 별도 뷰포트 배경. 전체 월드 너비로 늘리지 않고 화면 비율을 보존하며 작은 시차만 적용한다. |
| 지형과 인물 | 금속·목재 건물, 네모 수관, 주민 16명, 수집품·몬스터 | 기존 물리·NPC·아이템 좌표를 유지한 채 새 아틀라스로 연결한다. |
| 상시 정보 | 왼쪽 HP/XP, 가운데 지역, 오른쪽 목표, 아래 행동 바 | HP는 빨강, XP·진행은 초록, 행동 초점은 청록, 주요 버튼은 구리색이다. |
| 창 | 금속 프레임, 어두운 면, 밝은 한글, 아이템 칸 | `StarfrontArt`와 `ButtonArt`가 9-slice·상태·초점을 통일한다. 텍스트를 이미지에 굽지 않는다. |
| 활동 | 우주 작업실의 그림 그리기, 개척지의 집 짓기, 관측실 홈 | 배경과 도구·재료·의뢰인 이미지를 교체했다. |
| 학습 | 밝은 수학 도해와 작업 종이, 주변의 어두운 UI | 도형 위의 잉크와 주변 UI 글자 색을 분리했다. |

아틀라스가 합쳐지면서 바뀐 셀 번호는 호환 계층에서 매핑한다. 설원 장식이 성채로 바뀌거나 몬스터가 가방으로 표시되는 오류를 막는 회귀 검사를 추가했다. 배경 레이어는 월드에서 나갈 때 함께 숨긴다.

## 학습·작품 보존

사각형의 네 꼭짓점·포함 관계·학습 문항·정답·피드백과 저장 형식은 바꾸지 않았다. 플레이어와 건축물은 실제 네 꼭짓점으로 계속 그린다. 원래의 그림 배경·명화 학습 자료와 사용자 작품은 활동 콘텐츠로 보존한다. 벽돌 묶음은 새 단일 벽돌 이미지를 실제 개수만큼 반복한다. 돛은 사다리꼴, 깃발은 평행사변형으로 교정했다. 선택·격자·치수·UI를 제외하는 PNG 내보내기 규칙도 유지한다.

## 출처와 검사

새 원화는 모두 ImageGen으로 독자 제작했다. Starbound의 로고·스프라이트·UI 스킨·음원·추출 데이터는 배포물에 포함하지 않는다. [제작 기록](../assets/generated/starfront-v1/GENERATION.md)에 파일별 생성 ID와 프롬프트를 기록한다. 기존 라이선스 파일을 보존한다.

검증: `powershell -File tools/run_tests.ps1`. UI 대비·버튼 상태·키보드·1280/1600/783 크기 검사를 유지하고, 지역별 배경 전환·배경 숨김/복원·아틀라스 매핑 검사를 추가했다. 실제 렌더링은 1366×768과 800×600에서 홈·학습·그림·건축·공방·월드·가방·대화를 확인한다.

교체되어 더 이상 표시하지 않는 종전 월드·UI 이미지 파일은 저장소의 제작 이력을 위해 남기되 두 배포 프리셋에서 제외했다. 학습 그림·작업 종이와 수상 배지 등 실제 사용하는 자원은 포함한다.

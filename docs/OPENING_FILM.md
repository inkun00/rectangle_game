# 사각형 월드 — 지구에 온 사각이

55초, 가로 16:9, 한글 자막과 오리지널 음악·효과음으로 만든 앱 오프닝이다.
사용자는 내레이션 없이 자막과 음악·효과음 구성을 선택했다.

2026-11-10: 실행에 필요한 영상·포스터·행성 이미지는 저장소에 유지하고,
공유용 MP4·음악 WAV·자막·편집 소스·제작 전용 원화는 외부에 격리했다.
아래 제작 파일 경로는 격리 폴더에서도 동일하게 유지한다.
[보관 위치와 복원 안내](REPOSITORY_STORAGE.md)를 참고한다.

2026-11-14: 오프닝의 제목과 자막을 사각성 및 두 엔딩 분기에 맞추어 바꿨다.
같은 해상도와 프레임률, 그림, 음악으로 앱 영상을 다시 만들었다.
변경한 `scene.html`, `motion.js`, 자막 파일과 공유용 영상은 외부 격리 폴더의 `opening-sagakseong`에 보관한다.

## 표현과 제작

청록 `#22a99a`, 민트 `#8ce2c4`, 남색 `#071827`, 크림 `#fff5da`,
금색 `#f5c25c`, 산호색 `#ef826b`의 종이극. 실제 생성 원화와 정밀한 사각형
모션을 결합했다. 배경은 천천히 움직이고, 부품 조립·거래·충돌에는 별도의
움직임이 있다. 자막은 1600×900 기준 32px 이상으로 하단 안전 영역에 둔다.
장면 전환에는 사각형 대각선 닦기를 사용한다. 마지막 제목은 1.1초 정지한다.

공개 `motion-graphics` 스킬을 프로젝트의 `.agents/skills/motion-graphics`에 설치했다.
Claude Opus 5.5에서 사용되는 것과 같은 **코드 → 프레임별 캡처 → FFmpeg** 방식을
Codex에서 재현했다. Claude 모델 자체를 호출한 것은 아니다. Playwright Core만
프로젝트 로컬에 설치했고, 기존 Chrome과 Python의 FFmpeg를 사용한다.
별도 유료 영상 API, 구독형 편집기, 원격 업로드, MCP 설치는 필요하지 않았다.

무료 조건·라이선스·원저자 링크는 [OPENING_REFERENCES.md](OPENING_REFERENCES.md),
재생성 명령은 격리된 `tools/opening/RENDERING.md`,
작곡과 음량 검증은 `tools/opening/MUSIC.md`에 있다.
[제작 소스 복원 안내](REPOSITORY_STORAGE.md)에서 원래 경로를 확인한다.

## 앱 동작

첫 방문에는 사용자가 `이야기 시작`을 눌러 재생한다. 브라우저의 소리 재생을 위한
사용자 입력도 이 버튼에서 확보한다. 재생 중 일시정지·음소거·건너뛰기·Esc가
동작하고 끝나면 홈으로 돌아간다. 홈의 `오프닝 다시 보기`로 재감상할 수 있다.
시청 설정은 `user://quadrilateral_opening_v1.cfg`에 별도로 저장한다.
기존 캐릭터, 그림, 집, 학습과 모험 저장 파일은 이 설정과 분리되어 있다.

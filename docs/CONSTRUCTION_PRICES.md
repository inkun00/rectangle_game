화면의 부재는 작은 화면에서 조립할 수 있도록 단순화한 배치 단위이다. 화면 길이와 실제 상품 치수를 일대일 축척으로 제시하지 않는다. 실제 제품이나 사진의 비정형 외곽이 도형 분류의 근거가 되지 않으며, 게임에서 사용하는 네 꼭짓점으로 분류한다. 재료 밀도·질량·마찰·접합과 낙하 판정 또한 교육용 게임의 값이다.

## 추가 학습용 규격

2026-10-28에 추가한 아래 8종은 위 공개 가격을 재료량·면적·길이에 비례하거나 가공비를 더해 계산한 **게임용 추정가**이다. 실제 판매 규격이나 크기별 시세를 새로 확인했다는 의미가 아니다. 규격은 게임의 폭×높이이며 미터가 아니다. 반올림은 100원 단위로 한다.

| 추가 재료 | 게임 규격(칸) | 가격과 계산 |
| --- | --- | --- |
| 정사각 벽돌 2장 | 2×2 | 1,000원 = 500원×2장 |
| 낮은 직사각형 문 | 4×5 | 476,800원 = 572,100원×5/6 반올림 |
| 작은 정사각형 창 | 3×3 | 131,200원 = 233,300원×9/16 반올림 |
| 세로 직사각형 창 | 4×6 | 350,000원 = 233,300원×1.5 반올림 |
| 긴 직사각형 받침보 | 10×1 | 22,000원 = 13,200원×5/3 |
| 중간 사다리꼴 지붕 | 16×4 | 265,700원 = 177,100원×1.5 반올림 |
| 긴 평행사변형 판 | 6×2 | 33,100원 = 사이딩 7,700원×3장+가공비 10,000원 |
| 큰 마름모 장식 | 3.6×4.8, 한 변 3칸 | 73,800원 = 트림 15,950원×4개+가공비 10,000원 |

사다리꼴·평행사변형의 빗변, 마름모의 한 변은 폭·높이와 구별한다. 선택 자재의 네 꼭짓점에서 실제 변 길이를 계산하여 표시하고, 근삿값에는 ‘약’을 붙인다. 의뢰에는 도형 종류와 함께 정사각 창 한 변 4칸, 받침보 긴 변 6칸, 마름모 한 변 3칸, 긴 평행사변형 판, 지붕 긴 변 16칸 및 서로 다른 변 길이 종류 수를 선호 조건으로 제시한다.

이후 대표 모양별 8종, 총 40종으로 맞추기 위해 22종을 더했다. 이들의 가격도 기존 공개 기준 재료의 기하면적 비율로 환산한 100원 단위 **가공 추정가**이며, 석재·징크·구리 등 실제 재질별 판매가를 새로 검증한 값이 아니다. 8장 정사각 벽체는 벽돌 500원×8장으로 계산한다. 기존 18종 가격은 바꾸지 않았다. [40종 전체의 용도·규격·가격](CONSTRUCTION_MATERIALS.md)을 참고한다.

## 집 계약 금액과 기본 공사비

- [LG전자 2025-10-02 공개 자료](https://lg.co.kr/media/release/29442): MONO Core 27, 27㎡, 100,000,000원(VAT 포함).
- [LG전자 2026-06-29 공개 자료](https://lg.co.kr/media/release/30286): MONO Core 72, 72.9㎡, 199,500,000원부터 / MONO Core 82, 82.1㎡, 223,500,000원부터(VAT 포함). 옵션과 현장 환경에 따라 가격이 달라진다.

이들은 모듈러 주택의 특정 제품 가격 사례이며 일반 단독주택 평균 건축비가 아니다. 게임 계약은 이 실제 공개 가격의 금액 규모를 참고하고, 토지 구입은 다루지 않는다. 현재 화면에서 제작한 전면 조각 수십 개의 가격을 집 전체 가격이라고 설명하지 않는다.

게임은 `총 계약금액`, `먼저 받은 계약금`, `기본 공사비`, `전면 자재비`, `만족도 보너스`, `마지막에 받은 돈`, `순이익`을 구분한다. 기본 공사비 95,500,000 / 191,000,000 / 213,000,000원은 기초·골조·설비·실내·인건비·붙임 재료 등을 묶은 **게임용 예산**이며, 출처에 없는 비용 항목별 실제 비율을 주장하지 않는다.

처음 회사 운영금은 30,000,000원인 게임 설정이다. 의뢰를 받으면 계약금을 한 번 지급한다. 설계 중 자재비는 예정 지출로 예약되고 삭제·되돌리기로 되돌릴 수 있다. 집을 전달할 때 기본 공사비와 자재비를 한 번 차감하고, 총 계약금액에서 이미 받은 계약금을 뺀 나머지와 보너스를 한 번 지급한다. 다음 의뢰에는 이익이 남는다. 정산 기록과 잔액의 일치 여부를 저장 파일 복원 시 검증한다.

## 사각형과 큰 수 학습

정사각형 창문은 직사각형·마름모·평행사변형·사다리꼴의 성질도 만족한다. 기울였다는 이유로 분류를 바꾸지 않는다. 창문·문의 공간은 처음 배치할 때부터 예약하며 벽돌과 겹칠 수 없다. 주변 벽과 받침보를 지어 빈 공간을 확보한다.

금액은 `199,500,000원`과 `1억 9,950만 원`을 함께 읽을 수 있도록 제공한다. 원화와 누적 수익은 정수로 저장하고 모든 재료·계약금·정산은 100원 배수로 유지한다. 만족도는 공개된 부탁 충족 여부와 중력 검사로 계산한다. 필수 구조·문·창문 조건을 충족한 집은 추가 선호 조건을 일부 충족하지 못해도 제출할 수 있고, 보너스 차이가 생긴다.

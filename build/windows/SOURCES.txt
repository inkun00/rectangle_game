Quadrilateral World - art provenance and third-party sources

Active game artwork
assets/generated contains nine images generated specifically for this project
with the built-in ImageGen tool on 2026-10-13. Backgrounds, scenery, NPCs,
monsters, items, effects and UI textures use these images. The player character
is rendered from the user's quadrilateral drawing. Generation prompts and
atlas layouts: assets/generated/GENERATION.md and EXPANSION-GENERATION.md.
Notice: GENERATED-ART.txt.

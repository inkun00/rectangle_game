# 사각형 월드 오프닝 음악

이 오프닝을 위해 새로 작성한 **55초, 120 BPM, C장조 계열의 오리지널 음악과 효과음**이다. 외부 음악·악기 샘플·녹음·음성·음악 생성 API를 사용하지 않는다. 멜로디, 코드 진행의 배치, 악기 합성, 장면별 효과음은 `compose_music.py`에서 직접 정의한다. 우주를 닮은 잔잔한 시작에서 나무 타악기의 경쾌한 모험으로, 마지막에는 따뜻한 고향의 꿈으로 이어진다.

## 재생성

저장소 루트에서 실행한다.

```powershell
python tools/opening/compose_music.py
```

필요한 Python 패키지는 `numpy`와 `imageio-ffmpeg`다. 이미 설치된 패키지를 사용하며 스크립트가 네트워크 요청을 하지 않는다. `imageio_ffmpeg.get_ffmpeg_exe()`로 로컬 FFmpeg를 찾는다. 다른 파일로 출력하려면 `--output 경로.wav`를 지정한다.

기본 출력은 `output/opening/soundtrack.wav`이며 48,000 Hz, 16-bit PCM, 스테레오, 정확히 2,640,000프레임(55.000초)이다. 시드는 `441104`로 고정되어 같은 환경에서 음악을 재생성할 수 있다. 두 번의 측정에 의한 선형 loudness 정규화를 사용하며, 음의 변화를 압축해 없애는 방식으로 최대 음량에 맞추지 않는다.

## 작곡·동기화

| 시각 | 음악과 효과 |
| --- | --- |
| 0–7초 | C 계열의 부드러운 패드, 띄엄띄엄 울리는 높은 벨, 짧은 플럭 동기 |
| 7.15–9.1초 | 내려가는 음정과 가벼운 바람 효과가 불시착으로 이어짐 |
| 9.1초 | 낮고 짧은 충돌 소리. 이후 세 음의 코믹한 하강 |
| 11.58–13초 | 빈지갑의 작은 클릭과 두 개의 낮은 플럭. 반주가 잠시 가라앉음 |
| 13.25–14초 | 짧은 세 음으로 다음 장면을 준비 |
| 14–38초 | 마림바 선율과 아르페지오, 따뜻한 베이스, 절제된 킥·우드블록·셰이커 |
| 14.6초 | 아이디어가 떠오르는 세 음의 벨 |
| 24.0초 | 그림 판매에 맞춘 상승 코인 차임 |
| 31.0–36.0초 | 0.5초 간격의 부드러운 나무 클릭 11개로 집 조립 강조 |
| 37.4초 | 집 판매에 맞춘 상승 코인 차임 |
| 38–47초 | 패드 화음을 두텁게 하고 긴 벨 선율로 희망적인 분위기 |
| 47.0초 | 우주선의 꿈을 여는 여섯 음 상승 |
| 50–54초 | C화음으로 해결. 마지막 선율을 길게 유지하고 타악기를 줄임 |
| 54–55초 | 모든 악기와 잔향을 함께 부드럽게 페이드아웃 |

마림바는 감쇠하는 기본음과 짧은 비정수 배음, 플럭은 빠르게 줄어드는 배음, 벨은 세 개의 긴 배음으로 합성한다. 패드는 약간 다른 음정의 사인파를 겹친다. 베이스는 낮은 기본음과 두 배음, 타악기는 합성 파형과 고정 시드 잡음을 사용한다. 짧고 조용한 스테레오 반사음을 더해 나무 타격의 명료함을 유지한다.
